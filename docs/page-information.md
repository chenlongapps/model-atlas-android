# 当前页面字段

按当前实现整理（2026-11-10），只列“显示什么”，不规定新需求。视觉与布局见[设计规范](Design.md)，状态／导航见[架构](architecture.md)，来源及计价语义见[数据源说明](data-source.md)。

## 通用规则

- 模型／评测／中文来自 [Atlas](atlas-data.md)，服务商／价格来自 Models.dev；中文缺失回退原文。
- 缺失为“暂无数据”，显式空集合为“无”；能力支持／不支持／未知分开。详情摘要标签仅显示明确支持，没出现不等于不支持。
- token 限制：列表和对比可用十进制 K／M、最多一位小数，读屏精确；详情与价格档位门槛显示精确值。
- 价格：美元 / 百万 tokens，至少两位小数，保留更高精度；明确零价为 `$0.00`，不是缺失。参数量保留 B 原始有效小数，不补零、不从名称或组件之和推算。
- 权重状态三态；仅公开且许可短名去空白后为 1–16 字符时附短名，完整许可单独显示。开放权重不等于开源或允许商用。

## 模型页

| 区域 | 显示字段／操作 |
| --- | --- |
| 目录 | 应用名、总数；查询时匹配数／总数；收藏优先及发布时间顺序说明 |
| 查询 | 名称／规范 ID／LAB 搜索；已应用可移除条件；清空搜索、重置筛选、无结果清除全部 |
| 筛选面板 | 研发机构、权重公开状态、输入模态、输出模态、草稿匹配数；重置／应用 |
| 卡片身份 | LAB Logo、模型名、研发机构、权重许可标签、非交互收藏标识 |
| 卡片参数 | 发布时间、上下文长度、最大输出；不加参数量 |
| 卡片模态 | 输入／输出类别图标，读屏保留方向；具体 MIME 合并类别，未知保留原值 |
| 默认报价 | 输入／输出及已有缓存命中输入；其他缓存写入、推理、音频输入／输出价逐行显示；不显示服务商 |
| 报价档位 | 默认折叠，展开显示精确上下文门槛及已有单价，不选择档位或计算总价 |
| 状态 | 首次骨架、空目录、无匹配、首次失败／重试、下拉刷新、内联待更新／结果／错误 |

仅一条默认服务报价，选择规则见[报价选取](data-source.md#报价选取与展示)。筛选不含最低上下文／最大输出或有无报价；旧保存值忽略这些字段。

## 模型详情页

| 区域 | 显示字段 |
| --- | --- |
| 固定栏 | 返回、品牌／滚动后紧凑模型名、收藏／取消收藏状态 |
| 公共头部 | LAB Logo、完整模型名、研发机构、权重许可标签、描述、输入／输出模态；明确支持的推理、工具调用、结构化输出、附件、温度标签 |
| 概览：技术参数 | 上下文长度、最大输出、最大输入、总参数量、激活量、发布时间、知识截止时间 |
| 概览：模态 | 输入／输出文字与图标，缺失／空集合／未知分开，只取规范模型 |
| 概览：权重与许可 | 权重公开状态、完整许可 |
| 价格：每个服务独立一条 | 服务商 Logo／名称、模型服务 ID、该服务上下文长度、最大输出、基础输入／输出价；列表顶部统一价格单位 |
| 评测：每条配置独立一条 | 精确匹配的评测 Logo、完整名称、分数、明示单位；已有版本、推理档位、配置／变体、工具状态、评测说明 |

边界：
- 不额外展示规范模型 ID；来源无名称时既有名称兜底可能与 ID 相同。
- 概览不显示系列、能力明细、权重地址、格式／量化、资料、来源时效；参数量只保留两项，不显示口径、来源、组件或展开入口。
- 价格保留全部显式关联服务（含无价），仅取对应服务，不从规范模型、其他服务、档位或独立模式补齐；不显示扩展单价、模式／档位、服务能力、请求配置和来源时效。
- 评测数值四舍五入固定一位小数，文本原样；按英文名称 A–Z 忽略大小写，同名按未舍入数值降序、平分保留源顺序，文本／缺失稳定置后。不合并配置或推断可比性；不显示指标、方向、来源长链接、日期、数据集、执行框架或展开入口。实现入口为 `BenchmarkPresentation.kt`。
- 评测缺失／空集合有不同空态，合成测试数据显式提示虚构；无服务、无价、加载、读取错误、已移除分别反馈。底层完整记录不随 UI 精简删除。

## 评测页与完整排行榜

| 区域 | 显示字段／操作 |
| --- | --- |
| 总览页头 | “各模型最高成绩 · 配置可能不同 · 柱条使用局部刻度” |
| 总览卡片 | Logo、完整名称（同名多榜单附实际版本）、至多三项模型名／分数／机构色柱条，整卡进入完整排行榜 |
| 完整榜单简介 | Logo、名称、版本、类型；有非空说明时提供信息按钮／可滚动说明弹窗 |
| 完整榜单成绩 | 名次、模型名、分数及明示单位、机构色柱条；模型名后只附已有推理档位，不显示独立配置明细 |

总览不显示箭头、独立类型／版本行、指标、Top 3、名次数字、轴标签或重复入口。总览数值 `points` 视觉简写 `pts`，读屏及完整榜单保留原单位；不推断百分比。两页模型名与推理档位以 ` · ` 连接，空白不附后缀，读屏明确档位含义。

仅明确匹配定义且当前仍为 LLM 的模型参榜；同实际版本／指标／单位内、仅高分更优的有限数值，每模型取最高原值，同分并列。文本、未知方向和低分更优不在榜单展示，仍保留在模型详情。完整榜单无刻度栏、指标文字及排名／浏览提示；加载、错误本地重试、无数据、已移除各自反馈。排名与坐标计算见[架构](architecture.md#评测总览与完整榜单)。

## 模型目录中的收藏

| 状态 | 显示内容 |
| --- | --- |
| 当前可用 | 与普通模型相同卡片及收藏标识，可用收藏组内沿发布时间顺序 |
| 当前不可用 | 最后可用名称、研发机构、规范 ID、历史身份及当前不可用说明；不显示旧参数／价格 |

不可用收藏位于可用收藏之后、普通模型之前，可进入状态页取消；详情不额外显示规范 ID。唯一操作入口在详情右上角，无独立收藏导航页。
