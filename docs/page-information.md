# 当前页面字段

本文只维护当前页面“显示什么”，不是需求或验收清单。视觉与布局见[设计规范](Design.md)，状态／导航见[架构](architecture.md)，来源及计价见[数据源说明](data-source.md)。

## 通用规则

- 字段来源见[数据源说明](data-source.md#当前来源与边界)；中文缺失回退原文。
- 缺失为“暂无数据”，显式空集合为“无”；能力支持／不支持／未知分开。详情摘要标签仅显示明确支持，没出现不等于不支持。
- token 限制：列表和对比可用十进制 K／M、最多一位小数，读屏精确；详情与价格档位门槛显示精确值。
- 价格按[统一计价口径](data-source.md#计价约定)展示，零价为 `$0.00`。参数量保留 B 原始有效小数，不补零。
- 权重状态三态；仅公开且许可短名去空白后为 1–16 字符时附短名，完整许可单独显示。开放权重不等于开源或允许商用。

## 模型页

| 区域 | 显示字段／操作 |
| --- | --- |
| 目录 | 应用名；查询时显示匹配数／总数 |
| 查询 | 名称／规范 ID／LAB 搜索；已应用可移除条件；清空搜索、重置筛选、无结果清除全部 |
| 筛选面板 | 研发机构、权重公开状态、输入模态、输出模态、草稿匹配数；重置／应用 |
| 卡片身份 | LAB Logo、模型名、研发机构、权重许可标签、非交互收藏标识 |
| 卡片参数 | 发布时间、上下文长度、最大输出；不加参数量 |
| 卡片模态 | 输入／输出类别图标，读屏保留方向；具体 MIME 合并类别，未知保留原值 |
| 默认报价 | 输入／输出及已有缓存命中输入；其他缓存写入、推理、音频输入／输出价逐行显示；不逐卡重复报价标题和单位，不显示服务商 |
| 报价档位 | 默认折叠，展开显示精确上下文门槛及已有单价，不选择档位或计算总价 |
| 状态 | 首次骨架、空目录、无匹配、首次失败／重试、下拉刷新及其内联结果／错误；后台更新无提示且不替换当前列表 |

默认服务见[报价选取](data-source.md#报价选取与展示)；旧查询恢复时忽略已移除的上下文／最大输出门槛和报价筛选。

## 模型详情页

| 区域 | 显示字段 |
| --- | --- |
| 固定栏 | 返回、品牌／滚动后紧凑模型名、收藏／取消收藏状态 |
| 公共头部 | LAB Logo、完整模型名、研发机构、权重许可标签、描述、输入／输出模态；明确支持的推理、工具调用、结构化输出、附件、温度标签 |
| 概览：技术参数 | 上下文长度、最大输出、最大输入、总参数量、激活量、发布时间、知识截止时间 |
| 概览：模态 | 输入／输出文字与图标，缺失／空集合／未知分开，只取规范模型 |
| 概览：权重与许可 | 权重公开状态、完整许可 |
| 价格：每个服务独立一条 | 服务商 Logo／名称、模型服务 ID、该服务上下文长度、最大输出、基础输入／输出价；列表顶部统一价格单位 |
| 评测：每条配置独立一条 | 精确匹配的评测 Logo、完整名称、分数、明示单位；已有版本、推理档位、配置／变体、工具状态、评测说明 |

- 不额外展示规范模型 ID（名称缺失时可能用其兜底）。价格页含无价服务，不跨服务、档位或模式补值。
- `BenchmarkPresentation.kt` 将数值显示为一位小数、文本原样显示；按英文名称 A–Z 忽略大小写，同名按未舍入值降序，同分保留源顺序，文本／缺失置后。不合并配置。
- 评测缺失、空集合和合成测试数据分别反馈；无服务、无价、加载、读取错误、已移除也分别反馈。

## 评测页与完整排行榜

| 区域 | 显示字段／操作 |
| --- | --- |
| 总览页头 | 评测标题与刷新反馈 |
| 总览卡片 | Logo、完整名称（同名多榜单附实际版本）、至多三项模型名／分数／机构色柱条，整卡进入完整排行榜 |
| 完整榜单简介 | Logo、名称、版本、类型；有非空说明时提供信息按钮／可滚动说明弹窗 |
| 完整榜单成绩 | 名次、模型名、分数及明示单位、机构色柱条；模型名后只附已有推理档位，不显示独立配置明细 |

总览将 `points` 简写为 `pts`，读屏与全榜保留原单位，不推断百分比。两页仅在档位非空时用 ` · ` 接到模型名后，读屏说明档位含义。热度和坐标刻度不展示；排序、参榜和坐标规则见[架构](architecture.md#排名分榜与坐标)。

## 模型目录中的收藏

| 状态 | 显示内容 |
| --- | --- |
| 当前可用 | 与普通模型相同卡片及收藏标识，可用收藏组内沿发布时间顺序 |
| 当前不可用 | 最后可用名称、研发机构、规范 ID、历史身份及当前不可用说明；不显示旧参数／价格 |

不可用收藏位于可用收藏之后、普通模型之前，可进入状态页取消；详情不额外显示规范 ID。唯一操作入口在详情右上角，无独立收藏导航页。

## 对比页

| 区域 | 显示字段 |
| --- | --- |
| 两侧选择区／候选面板 | 展开态显示 LAB Logo、完整名称、研发机构和更换入口；吸顶态显示 Logo、完整名称与下箭头；面板可选择／替换／移除，另一侧已选项禁用，候选本地搜索并收藏优先 |
| 关键规格 | 上下文、最大输出、最大输入、输入／输出模态、权重公开状态；「仅看差异」隐藏两侧都明确且相同的字段 |
| API 价格 | 默认报价服务商、单位、基础输入／输出价及已有额外单价（缓存读／写、推理、音频输入／输出）；默认报价口径和阶梯计费说明放入信息弹窗。不显示报价服务 ID 或档位价格 |
| 评测分数 | 评测 Logo、名称、两侧模型名称及成绩／单位；同名项附指标，虚构测试数据明确标识。不展示版本或思考档位；未确认评测条件一致的项目及不同的配置原文放入信息弹窗 |
| 基本信息 | 发布时间、系列、知识截止时间、总参数量／激活量 |
| 能力特性 | 附件、工具调用、结构化输出、推理、温度 |
| 权重与许可 | 完整模型许可 |

正文不重复展示研发机构。规格和报价字段两侧都缺失时不展示，单侧缺失标「暂无数据」；保留 `false`、零与空模态。正文及候选不额外显示规范 ID，但可按 ID 搜索；无名称的已选槽位用序号占位名称。参数／能力只取规范模型，价格直接沿用列表默认服务，不混服务或模式、不计算总价。评测分数格式沿用详情；配对规则见[架构](architecture.md#双模型对比的数据与状态)。
