# 外观设置与持久化

本文维护外观偏好的状态、持久化与异常契约；页面字段见[字段表](page-information.md#设置页)，尺寸与视觉见[设计规范](Design.md#设置与-debug)。AI 调用入口、导入导出及备份恢复功能未实现。

## 配色规则

- 明暗模式为浅色、深色、跟随系统，默认跟随系统；与颜色来源独立。强制明暗也可以使用系统动态色。
- 颜色来源为系统动态色、14 种预设、自定义色相，默认系统动态色。预设／自定义选中时优先使用对应配色，不叠加系统动态色；系统动态色不可用或设计预览关闭动态色时使用 Material 3 固定备用方案。
- 自定义只有一个 0–360° 色相滑块，不显示颜色名称、数值或精调控件。内部使用 MaterialKolor 的 Tonal Spot 完整色板生成，低饱和度预设使用 Neutral 风格；明度、饱和度与前景角色由算法调整，不保证滑块颜色等于最终 `primary`。使用公开 API，不调用 Views Material 中受限的 utilities API。
- 所有页面、玻璃导航底色与系统栏图标同步应用主题；品牌 Logo 继续保留原色及固定白底。系统最初绘制的启动底色仍由窗口 DayNight 资源决定，不保证匹配用户自定义颜色。

## 页面与交互

- 设置 → 外观打开独立子页，保留但不放置主分页器与底栏，按钮及系统返回回到设置。子页和正文位置支持状态恢复。
- 明暗与颜色来源独立选择，预设／自定义不覆盖明暗偏好；控件随宽度和字号适配，不缩小系统字体或点击区域。
- 网格用实际生成的色板组合及选中标记表示，不显示预设颜色名称；系统动态色有明确文字。每项保留不可见的读屏名称、选中态及标准操作。
- 自定义有历史色相时，点击立即启用并打开取色器；无历史时仅打开，默认从蓝色色相 220° 开始，首次移动才启用。取色器只有标题、关闭按钮和一个彩虹滑块，保留标准读屏／键盘操作。
- 拖动逐次更新整个应用，停顿 300ms 或松手时保存；关闭按钮、遮罩、系统返回及离开页面不撤销，关闭／Activity 暂停时主动提交尚未保存的变化。进程在提交前被杀时恢复最后成功保存值。
- 切换到系统色或预设不删除自定义历史；切换明暗不改变颜色来源。无额外“应用／保存”按钮。

## 分层与状态

路径均相对于 `app/src/main/java/io/github/chenlongapps/modelatlas/`：

| 路径 | 职责 |
| --- | --- |
| `data/model/AppearanceSettings.kt` | 无 Android／Compose 依赖的偏好模型、稳定预设标识和参数校验 |
| `data/repository/SettingsRepository.kt` | 持久化 Flow、原子读改写及明暗／来源／色相修改接口，供普通界面及后续工具复用 |
| `data/repository/DataStoreSettingsRepository.kt` | Preferences DataStore 编解码与事务；不吞掉读取异常，不自动覆盖损坏文件 |
| `di/DataModule.kt` | 单例 DataStore 与 Repository 绑定 |
| `ui/settings/AppearanceViewModel.kt` | Activity 级首读／重试、全局乐观预览、300ms 防抖与串行写入、失败回滚 |
| `ui/settings/AppearanceScreen.kt` | 无注入 Screen、配色网格、示例卡与取色器及独立深浅／窄屏大字预览 |
| `ui/theme/Theme.kt` | 系统／备用／生成色板解析，网格与全局主题共用实现 |
| `MainActivity.kt` | 生命周期感知收集主题、首次绘制等待、系统栏图标／窗口底色和错误提示 |

Repository Flow 只代表已持久化值，不包含拖动预览。ViewModel 在内存维护预览与最后保存值，写入时合并字段变更而非用旧快照覆盖整份设置，避免吞掉其他调用方的字段更新。只取消防抖计时，不因新拖动取消已经开始的写入。取消不当作保存失败。

### 启动和异常

- 首次读取最多等待 1.5 秒，读成功且主题首次组合完成后放行首帧；不阻塞主线程、不通过重建 Activity 切换主题。
- 超时／读取失败：放行主界面，使用默认主题并明确提示；外观页禁用修改，提供“重试”。重试成功后应用已有偏好并恢复编辑，不重新遮挡主界面。
- 保存失败：回滚到最后成功保存的状态并明确提示；失败期间新增但未保存的预览同时丢弃，避免后续提交把失败预览重新带回。
- 未配置字段使用默认值；非法枚举、色相、字段类型或损坏文件作为读取错误，不伪装成首次安装、不清空原文件。

## 存储和备份边界

文件为应用私有目录 `files/datastore/appearance.preferences_pb`。字段包括明暗模式、颜色来源、预设稳定标识、可空自定义历史色相；不存储系统生成的整套色板。

`data_extraction_rules.xml` 的 cloud backup、device transfer 及旧 `backup_rules.xml` 均只排除此新增文件，不改变其他数据的备份规则。Debug／Release 使用各自应用沙盒，偏好互不影响。没有新增 Room 表、网络请求或 AI 工具。
