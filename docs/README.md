# 项目文档

本目录存放供 agent 和开发者按需阅读的项目背景、架构与数据源说明。文档描述当前实现，不将功能规划视为已完成；如与代码不一致，应核实并更新文档。

## 阅读顺序

1. 阅读根目录的 [AGENTS.md](../AGENTS.md)，了解开发约束、构建命令与验证方式。
2. 通过 [项目 README](../README.md) 了解应用目标与功能概况。
3. 根据当前任务阅读下表中的相关文档。
4. 通过 [TODO.md](../TODO.md) 查看任务规划与完成状态。

## 文档索引

| 文档 | 内容 | 何时阅读 |
| --- | --- | --- |
| [架构说明](architecture.md) | 代码入口、分层职责、状态流转与现有测试 | 修改界面、ViewModel、仓库或应用结构前 |
| [数据源说明](data-source.md) | 本地数据现状、Models.dev 地址分歧与接入前核实事项 | 接入 API、映射字段、展示价格或设计缓存前 |

## 维护原则

- 使用中文说明，保留代码标识、命令和路径的原始写法。
- 只记录有助于后续任务的必要信息；新增文档时同步更新本索引，并标明适用任务。
- 当前实现、已验证事实和待确认事项应明确区分，不把推测写成约定。
- 构建规范以 `AGENTS.md` 为准，任务进度以 `TODO.md` 为准，不在本目录复制维护。
- 修改实现后同步更新相关说明；链接优先使用相对路径，便于直接定位源码和其他文档。
