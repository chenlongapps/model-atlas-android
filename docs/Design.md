# 全局 UI/UX 设计规范

这是 ModelAtlas Android 的全局设计契约。具体页面的布局和交互见[页面设计约束](page-design.md)，显示字段见[页面字段](page-information.md)，状态与导航机制见[架构](architecture.md)。UI 变更按[仓库协作流程](../AGENTS.md#ui-修改)执行。

## 设计理念

- 简洁、现代、克制。先让内容、状态和主要操作清楚可见，再考虑装饰。完整信息优先于固定高度和强制单行；说明按需披露，文案见[文案与信息披露](../AGENTS.md#文案与信息披露)。
- 决策顺序：Android 平台与无障碍要求 → Material 3 语义 → 本契约 → 项目已有组件和惯例 → 外部示例。Material 3 默认外观不替代项目已有且符合平台语义的设计。

## 视觉语言与 Token

- **色彩**：按角色使用 `MaterialTheme.colorScheme`，让强调色服务于操作或信息层级。配对检查前景与背景的对比度，不仅靠颜色传达意义，不照截图取色。
- **字体与层级**：用 `MaterialTheme.typography` 区分标题、正文和辅助信息。通过字号、字重与位置突出重点，不用过多强调样式。
- **间距与容器**：沿用已有间距及对齐关系，用留白表达分组。容器只用于确实需要分隔、承载操作或浮于正文之上的内容；普通容器用 `MaterialTheme.shapes`，有明确功能或品牌用途时才用专用形状。不用叠加卡片、阴影、渐变或描边来填补层级。
- **图标与品牌**：同义操作复用已有图标；图标入口要有可读名称。品牌 Logo 保留原色、比例和既定底座，不随主题染色。
- **动画与反馈**：动效用于说明状态变化、操作结果或空间关系；遵循系统动画倍率和减少动态效果的设置。反馈应就地、可感知，非阻断状态不要打断阅读；禁用动画时仍能理解和完成操作。
- **事实来源**：[`ModelAtlasTheme` / `Theme.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/theme/Theme.kt) 与 Material 3 的代码定义是颜色、字型和形状 Token 的唯一依据。文档引用 Token 名称，不抄录数值。

## 组件复用

- 优先用 Material 3 组件或项目中已符合其语义的组件；相同功能保持视觉、状态和交互一致，不另造同义组件。
- 复用的是主题、组件和交互惯例，不是整页模板。按任务选择最清楚的布局，不强制套用卡片或固定页面结构。

## 适配与无障碍

- 支持浅色、深色、动态色和自定义配色。按可用空间、实际内容与字体缩放换行、重排或滚动，不为统一而缩字、裁切重要内容或压缩触摸区。
- 可交互触摸区域通常至少 **48 × 48 dp**。支持键盘焦点与操作、TalkBack、RTL 和系统返回；关键手势提供等效操作，浮层和系统栏不得遮挡操作或重要内容。
