# ModelAtlas UI/UX 设计规范

本文以当前 Compose 实现为基准，记录 ModelAtlas 的视觉语言、组件与交互约定，供界面设计、开发及回归检查使用。本文不是新一轮界面改版方案，也不表示规划功能已经实现。

架构与状态实现见[架构说明](architecture.md)，字段、计价与许可语义见[数据源说明](data-source.md)，功能进度统一见 [TODO.md](../TODO.md)。

## 1. 设计原则

- **紧凑且易扫读**：以模型卡片组织信息，优先呈现模型名称、研发机构、关键限制与单价，通过字号、色调及留白区分层级。
- **真实而不补造**：保留未知、明确为空和零值的区别；不把开放权重描述为开源，不把单条报价描述为全网最低价。
- **主题一致**：使用 Material 3 语义颜色和字体角色，明暗与颜色来源独立选择，默认跟随系统明暗及动态取色，不复制参考图中的固定配色。
- **渐进展开**：卡片保留核心信息，上下文价格档位按需展开；筛选在独立面板中编辑，确认后才影响列表。
- **保持浏览连续性**：刷新失败不清空已有目录；普通切页保留阅读位置、查询条件与报价展开状态，不强制滚回顶部。
- **紧凑不牺牲可用性**：窄屏及大字体优先换行，不通过缩小字号、截断价格或减少点击区域维持固定高度。

## 2. 页面与信息结构

```text
主界面（横向分页 + 悬浮底部导航）
├── 模型
│   ├── 应用名与目录数量
│   ├── 内联状态提醒（有状态时）
│   ├── 搜索、筛选入口与已应用条件
│   ├── 发布时间排序说明
│   └── 模型卡片 → 独立模型详情 / 加载骨架 / 空目录 / 无匹配 / 错误状态
├── 收藏
│   └── 收藏时间倒序卡片 → 模型详情 / 不可用状态页
├── 对比
│   ├── 双模型选择卡片与本地搜索选择面板
│   └── 基本信息、输入输出、API 价格、能力特性、权重与许可
├── 设置
│   ├── 外观 → 明暗、动态色／预设／自定义色相及效果预览
│   └── 数据来源与许可 → 独立全屏说明页
└── 调试（仅 Debug，与模型／收藏／对比／设置同级）
    └── 应用／设备信息、本地目录统计、手动刷新及诊断复制
```

### 模型目录

- 页头、状态提醒、搜索区和排序说明都是列表内容，随卡片正常滚动；不使用固定或吸顶应用栏，下滑时不单独弹出页头。
- 默认按发布时间倒序排列，当前不提供排序切换。
- 无查询时展示目录数量；有搜索或筛选时展示匹配数与总数。首次加载不显示虚假的零模型数量。
- 每个规范模型一张卡片；点击卡片打开详情，价格标题作为独立操作仅展开／收起档位，不触发跳转。卡片提供“查看模型详情”的读屏操作标签，不新增尾部箭头。

### 模型详情

- 顶部返回栏固定在系统安全区内，初始复用 `app_name` 显示“Model Atlas”及“模型详情”读屏语义。大模型名接近栏下边缘时，品牌文字与大标题渐隐，紧凑模型名配合最多 8dp 的向上位移渐显，滚回时反向恢复；进度连续跟随滚动位置。紧凑名称使用 `titleMedium` 单行省略，读屏保留全名，展开身份区仍完整换行。交接时仅可读一份模型标题，返回按钮始终可用。
- 独立全屏页面，按“概览／价格／评测”三个标签切换，默认概览；固定返回栏下为居中身份区 → 独立参数卡 → 标签栏 → 标签正文，这些内容随列表滚动。返回栏两层文字始终参与测量，过渡不改变栏高或推动正文。隐藏主分页器与悬浮导航，按钮及系统返回恢复原目录阅读位置、查询与价格展开。
- 页头不装在整块圆角卡片里，也不绘制彩色渐变或单独底色，直接沿用页面 `surfaceContainerLowest` 背景；88dp 品牌 logo、`headlineMedium` 模型名、研发机构与权重许可居中纵排，描述左对齐，方向模态和能力标签居中。品牌原色、固定白底、圆角比例、权重及模态标签仍复用列表组件；列表维持原有 56dp logo 和横向紧凑身份布局。缺失描述显示“暂无模型描述”，仅能力明确为 true 时显示相应摘要标签，不从上下文长度生成“长上下文”等能力认定。
- 参数卡独立使用 `surface`、24dp 圆角与 16dp 内边距，不添加阴影，与整体卡片风格一致；取消彩色背景交界及相关测量逻辑，不用负间距或固定高度。发布时间／上下文／最大输出常规字号优先三列，窄屏或大字体降为 1–2 列；数字使用列表已有 K／M 缩写，读屏保留完整数值与单位，日期保留来源精度。
- 概览依次展示“模型能力 → 技术参数 → 权重与许可 → 相关资料 → 数据来源与时效”五个独立卡片：能力保留输入／输出方向和支持／不支持／暂无数据三态，技术参数展示完整 ID、系列、发布时间、知识截止时间和精确的上下文／输入／输出限制，权重区展示完整许可；价格保留全部服务商及各模型服务报价；评测展示来源原始记录。正文 `surface` 分区仍为 24dp 圆角与 20dp 内边距，长文本允许换行，不补造功能或数据。
- 常规宽度三个标签等宽排列；窄屏或大字体空间不足时改为可横向滚动标签，保留完整标签文字、选中指示和 48dp 最小触摸高度，不压缩字号或截断标题。点击标签或在下方正文左右滑动切换“概览／价格／评测”，只有 `DetailSection` 正文参与横向分页；身份区、参数卡及标签栏共用一份，不随横滑移动或因切页跳动，在身份区横滑也不切页。选中态同步当前页，首末页不循环，RTL 下方向随布局调整。各标签正文独立保存滚动、链接反馈和展开状态；纵向上滑先滚走公共头部与标签栏，再滚正文，下滑时正文到顶后恢复公共区域。顶部返回栏标题仅跟随公共头部的纵向位置变化。
- 能力明确区分支持／不支持／暂无数据，集合缺失与显式空集合分别为“暂无数据”与“无”。权重许可不限 16 字符，不把开放权重称为开源。
- 服务商分组标题下保留每一个显式关联的模型服务，包含未提供报价的服务；基础价与具名独立模式分区，USD / 1M tokens 单位保留，价格用主题色与加粗字号突出，按宽度和字号使用 1–3 列。档位默认折叠，展示精确门槛而不自行解释等号归属或累进计费；服务自身的参数与来源另行展开。
- 链接明确标注外部打开并显示地址；仅有效 HTTP(S) 可点击，非法地址或无浏览器时提供行内说明，不崩溃。
- 评测集展示本地规范模型的 Benchmark 原值：名称、分数、指标、来源、日期、版本、配置／变体、数据集、评测框架；保留同名不同配置记录和来源顺序，不推断百分比、分数方向、综合排名或跨口径可比性。缺失列表显示“暂无评测数据”，显式空列表说明来源未列出记录；安全 HTTP(S) 出处可外部打开，普通出处名称及不安全地址仅作为文字。
- 加载提供进度反馈，读取错误提供本地重试；模型被移除／不再收录时提供返回操作，无关联服务不冒充模型不存在。保存模型 ID、所选标签、各标签独立滚动和展开状态，异步加载不重置已保存位置，不保存整份目录。标签栏滚出视口后仍可直接横滑切页，也可滚回标签栏点击切换。

### 收藏

- 底栏与详情收藏按钮统一使用书签图标，未选中为描边、选中为实心，两态保持相同外轮廓。
- 独立底栏页，无搜索、筛选、分组或联网刷新。按收藏时间倒序，取消后重新收藏排到最新；目录更新不改变顺序。可用条目复用现有模型卡片、当前报价及展开行为，保留滚动与展开状态。
- 唯一收藏操作位于详情固定返回栏右侧，提供“收藏模型／取消收藏”的按钮名称及状态语义，保存期间禁用重复提交。收藏成功留在详情；取消收藏保存成功后返回来源页，无二次确认；失败保留页面及原状态并明确提示。
- 不可用收藏显示最后可用名称、研发机构和规范 ID，注明历史身份与“当前目录不可用”；点击仍可进入详情状态页并取消收藏，不显示历史参数或价格。同 ID 恢复后自动展示当前卡片，不按同名迁移收藏。
- 收藏列表区分加载、读取失败及尚无收藏；读取失败只提供本地重试。系统安全区、状态栏保护与实测底栏避让沿用目录布局。两个列表都存在同一模型时，详情动画仅匹配真实来源页。从收藏详情主动取消时，先保存成功，再缩回仍暂留在原位置的卡片；返回转场完全结束后，卡片用 180ms 淡出，其余条目用 220ms 平滑补位，无额外停顿。最后一张卡片淡出后才显示空态；临时卡片不可交互或读屏。不冻结整个列表，保存失败留在详情；不可用收藏沿用淡出返回，再执行卡片淡出。外部删除、目录下架和读取失败不扩大旧内容保留范围，系统关闭动画时立即应用最终状态。

### 双模型对比

- 模型选择列表及搜索结果均将当前目录内的收藏模型放在前面，收藏／非收藏两组内部保留目录原有发布时间顺序，不显示额外分组或收藏操作；另一侧已选模型仍禁用，已下架收藏不补入候选。切回对比页读取最新本地收藏，不改变模型目录或收藏页排序。
- 对比为独立顶层页，保持悬浮底栏，无返回按钮。顶部两个轻量圆角模型卡片并排时动态等高，间隔 12dp，不再用“VS”占用横向宽度；只展示品牌 logo、完整名称、研发机构和更换／移除操作，权重许可留给正文分区。名称与研发机构分别按两侧文字在当前宽度／字号下的较大高度预留空间，使机构及更换操作对齐；完整名称可超过两行，不缩小字号、不截断、不写死卡片高度，替换后重新计算。窄屏／大字号空间不足时卡片上下排列，各自随内容增高，不共享字段高度。未选择／只选一个时明确引导，选择面板按名称、稳定 ID 和 LAB 本地搜索，另一侧已选项禁用；关闭面板不改变选择。
- 参考逐项对照表组织“基本信息／输入输出／API 价格／能力特性／权重与许可”圆角分区。手机优先采用字段标题在上、两侧数值各占半宽的布局，列间留白 16dp，以淡横线区分字段，不绘制竖线；分区内部可用宽度达到 `600dp × fontScale` 才展示字段名＋两个模型列，低于 `240dp × fontScale` 时改为上下排列并重复模型名。并排时每个分区使用一行双模型名列头，不再新增“模型名称”参数行。保留完整名称与许可，不压缩字号。沿用动态深浅主题、随包品牌素材及原有 K／M 缩写，读屏逐项包含模型名、字段名与精确值。
- 模型 ID、报价服务 ID 和完整许可默认折叠，提供至少 48dp 高的明确查看／收起操作及展开状态语义；展开后保留完整原值，缺失值仍明确标注“暂无数据”。这些展开状态与价格档位一样保存在页面状态域，离屏回收、切页与异步恢复不丢失，替换模型后重置。
- 报价仅沿用列表默认选择，标出服务商与服务 ID，保持 USD / 百万 tokens 单位、完整单价和精确档位。档位独立展开，不解释门槛等号归属，不混合不同服务或独立模式，不使用暗示性价比的进度条或最低价／胜负标签。能力只展示已有字段的三态，不从名称或价格推断编程、金融、智能体任务等能力。
- 保存两个模型 ID、正文位置和档位展开状态；异步恢复的加载内容不覆盖正文滚动状态。模型移除／读取错误立即停止展示该模型的旧对比内容，提供替换／移除或本地重试；离屏关闭选择面板，不额外联网。列表安全区与目录一致，顶部绘制不占布局空间的主题半透明渐变，保护内容滚入状态栏时的系统图标；末尾避让实测悬浮导航高度。

### 设置与说明页

- 设置页提供“外观”与“数据来源与许可”独立子页，不承载调试入口；Release 不显示调试标签或空白占位。
- 外观页顶部明暗单选，16 项配色网格（系统动态色＋14 预设＋自定义）及包含标题／正文／按钮／标签的紧凑示例卡。网格随宽度和字号使用 2–4 列；明暗选项空间不足时纵排。预设不显示名称，保留读屏名称与选中语义；系统动态色有明确文字。
- 自定义取色器仅提供单色相滑块、标题与关闭按钮，不显示颜色名称／数值或精调控件，保留标准读屏和滑块操作。已有历史色点击立即恢复，无历史仅打开、首次移动才启用；全局实时预览，停顿／松手保存，关闭及返回不撤销。保存失败回滚并提示，读取失败暂禁编辑并提供重试。完整规则见[外观设置](appearance-settings.md)。
- 说明页集中展示数据来源、独立第三方身份、价格适用条件和随包 MIT 许可全文，不依赖目录加载成功。
- 打开说明页隐藏主分页器与悬浮导航，避免触摸和读屏穿透；返回按钮及系统返回都回到设置页。
- 说明页顶部返回区固定在安全区内，正文独立滚动并支持位置恢复；模型列表不重复放置来源或价格说明卡片。
- 调试是仅 Debug 存在的第五个顶层标签，沿用设置页的滚动大标题、主题色与大圆角分区，不显示返回按钮、不隐藏底栏，系统返回遵循现有顶层行为。应用信息、设备信息、本地目录统计和手动刷新分区展示，字段值可完整换行，底部提供复制诊断信息，并为实测悬浮导航高度增加内容留白。切页与恢复保留阅读位置；只在切入停稳、重读或刷新后读取统计，离屏预组合不读库。统计标明全量目录三表记录与非实时读取，未知不显示为零，读取失败明确标记旧数；刷新过程禁用重复操作并显示状态，不清空目录。支持浅深主题、窄屏大字体及 RTL，不展示密钥、设备唯一标识或原始请求内容。

## 3. 视觉基础

### 3.1 颜色与主题

主题定义位于 [`Theme.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/theme/Theme.kt)。设置 → 外观提供浅色／深色／跟随系统及独立配色来源。系统动态色在强制浅深下仍可使用；选中预设或自定义时生成完整语义色板，以可读性优先；动态色不可用时使用 Material 3 默认备用方案。

| 语义角色 | 当前用途 |
| --- | --- |
| `surfaceContainerLowest` | 主页面背景 |
| `surface` | 模型卡片与筛选面板背景 |
| `surfaceContainerLow` | 搜索框、普通信息标签、内联提醒和设置说明区块 |
| `onSurface` / `onSurfaceVariant` | 正文／次要信息及辅助图标 |
| `primary` | 研发机构名称、API 价格标题、重点单价及选中强调 |
| `secondaryContainer` / `onSecondaryContainer` | 已应用条件及活动筛选入口；筛选选项使用半透明选中底色 |
| `tertiaryContainer` / `onTertiaryContainer` | 开放权重标签 |
| `outlineVariant` | 能力与价格分隔线、价格列间分隔线，按组件降低透明度 |
| `error` | 错误状态图标等错误强调 |

品牌 logo 是例外：保留原色，始终使用固定白色圆角底，不随主题着色。其他界面不硬编码参考图中的绿色或橄榄色。

预览关闭动态取色以保证可复现；需要稳定配色的测试使用 `ModelAtlasTheme(dynamicColor = false)`，动态取色另行验证。

### 3.2 字体层级

沿用 Material 3 `Typography` 的字号与行高；主题将 `headlineMedium`、`titleLarge` 和 `titleMedium` 默认字重设为 `SemiBold`，不固定系统字号缩放。

| 内容 | 字体角色 |
| --- | --- |
| 模型页应用名、设置页标题、详情头图模型名 | `headlineMedium` |
| 筛选面板标题 | `headlineSmall` |
| 说明页顶部标题、状态卡片标题 | `titleLarge` |
| 列表模型名、筛选分组标题 | `titleMedium` |
| 核心单价 | `titleMedium`，局部使用 `Bold` |
| 研发机构名、目录说明、一般正文 | `bodyMedium` |
| 参数、价格类别、补充价格与辅助说明 | `bodySmall` |
| 信息标签、导航标签、排序说明 | `labelMedium` |
| API 价格标题与计价单位 | `labelSmall`（默认 11sp / 16sp 行高） |

### 3.3 圆角、尺寸与间距

以下是已实现的常用值，不要求所有组件机械地使用同一个间距。

| 项目 | 当前值 |
| --- | --- |
| 主题圆角 `small / medium / large / extraLarge` | `10 / 16 / 24 / 32dp` |
| 模型卡片圆角／内边距／卡片间距 | `24 / 16 / 16dp` |
| 模型列表水平内容留白 | 系统安全区之外再加 `16dp` |
| 卡片主要内容组间距 | `12dp` |
| 列表 logo 底座／内部图形／底座圆角 | `56 / 44 / 14dp`；详情放大至 `88dp` 底座，其余等比放大 |

## 4. 核心组件

### 4.1 模型卡片

实现：[`ModelCard.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/modellist/ModelCard.kt)。

列表与详情的共用展示组件位于 [`ModelPresentation.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/model/ModelPresentation.kt)：`ModelIdentity`、`ModelWeightsBadge`、`ModelInfoBadge`、`ModelModalities` 和 `ModelCoreMetrics`。身份支持横排／居中纵排，参数支持紧凑行／独立参数卡布局；身份元素分别保留 `Modifier` 接口。详情页头组装位于 [`ModelDetailHeader.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/modeldetail/ModelDetailHeader.kt)。[`ModelSharedTransition.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/model/ModelSharedTransition.kt) 与页面外壳同时协调整卡容器及内部身份共享过渡：容器按规范模型 ID 匹配，身份按规范模型 ID + 元素角色匹配，两类键互不混用，不使用 LAB 作为动画键。

卡片自上而下分为五组：

1. **身份区**：左侧品牌 logo；右侧模型名、研发机构和合并的权重许可标签。名称允许换行，不为保持固定卡片高度裁切。
2. **参数区**：发布时间、上下文长度、最大输出以“图标 + 数值”呈现，空间不足自动换行。
3. **模态区**：输入模态 → 输出模态，使用图标标签；视觉上不重复“输出：”前缀，读屏保留方向与模态名称。
4. **细分隔线**：区分模型能力与价格，不增加额外的内层容器。
5. **价格区**：与外层卡片共用背景、左对齐，不嵌套独立底色、圆角或额外内边距。

信息标签是说明，不是筛选按钮，不借用可交互 `FilterChip` 暗示点击能力。

整卡点击不显示 Ripple 涟漪动画，保留打开详情的点击行为与无障碍语义；价格档位标题等独立操作的点击反馈不变。

### 4.2 研发机构与品牌素材

- 面向用户统一称“研发机构”；已知名称使用品牌惯用写法，如 OpenAI、DeepSeek、xAI，未知值保留原文。
- logo 按模型稳定 ID 的 LAB 前缀匹配随包素材；没有素材时使用兜底图，不借用其他机构的图案，不运行时下载。
- logo 旁已有机构文字，不重复增加读屏描述。
- 该标签来自 ID 前缀，不构成独立核实的开发商认定，来源说明保留此边界。

实现：[`LabLogo.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/modellist/LabLogo.kt)、[`LabDisplayName.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/modellist/LabDisplayName.kt)。

### 4.3 API 价格区

- 标题组合为“API 价格 · 美元 / 1M tokens”，计价单位不得省略或误写为每次请求。
- 输入、输出及存在时的缓存命中输入分列显示；按宽度与系统字号切为 1–3 列，列内标签在上、重点单价在下。
- 标题与指标区域间距为 `4dp`，指标内部间距为 `2dp`，指标换行间距为 `8dp`。不通过缩小字体或近似报价适配窄屏。
- 缓存写入、推理和音频等额外单价逐行显示；不合计费用，不展示服务商名称或“官方”“最低价”等标签。
- 有上下文档位时，标题整行可展开／收起，箭头收起朝下、展开朝上；无档位则没有箭头和无效点击操作。
- 标题保持紧凑视觉高度，通过 `clickable` 向布局外扩展触摸区域，保留至少 `48dp` 的触摸高度，不重新用 `48dp` 布局高度撑开标题。
- 档位默认折叠，展开状态可恢复；门槛始终显示完整精确数值，不使用卡片参数的近似缩写。

报价选择及适用条件只在[数据源说明](data-source.md#报价选取与展示)维护；界面不将所选报价当作无条件通用价格。

### 4.4 搜索与已应用条件

实现：[`ModelCatalogControls.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/modellist/ModelCatalogControls.kt)。

- 搜索使用无描边、填充底色的胶囊框，按名称、稳定 ID 或研发机构原始 ID 实时本地匹配，不新增网络请求。
- 有输入时显示清空按钮；键盘搜索键收起键盘，不增加第二次提交步骤。
- 筛选按钮位于搜索框下方，展示图标、条件数量与展开箭头；存在筛选条件时用主题容器色强调。
- 已应用条件使用可移除胶囊标签并允许换行；点击标签移除对应条件。
- 搜索清空只清空搜索；外部“重置”只清除筛选、保留搜索；无结果卡片中的清除操作才清除全部条件。
- 条件数量不是标签数量：研发机构多选合计一组，每个必需模态分别计数，其余字段各计一项。

### 4.5 筛选面板

- 使用大圆角底部弹层，不设额外关闭图标；点击遮罩、系统返回或下滑关闭都放弃未应用修改。
- 上方固定标题与草稿匹配数，中间分组内容滚动，底部固定等宽“重置／应用”按钮；应用按钮不重复显示条件数。
- 普通字号内容高度比例为 `75%`；`fontScale > 1.5` 时提高到 `90%`，为大字体提供更多滚动空间。
- 分组包含研发机构、权重公开状态、输入／输出模态、最低上下文／最大输出 tokens 和有无列表报价。
- 选项是胶囊：未选用浅色容器，选中用主题色 `1dp` 描边与淡底；模态选项同时显示图标与文字。
- 研发机构默认显示最多八项，已选项始终可见；超出时提供“更多／收起”，已选项超过八个时不隐藏它们。
- 打开时从已应用条件建立独立草稿，修改立即更新预览数量；点击“应用”才提交，面板内“重置”只修改草稿并保留搜索。
- 刷新后已选但不再存在于目录的选项仍允许取消，不因零匹配隐藏当前选择。

### 4.6 悬浮底部导航

实现：[`GlassNavigationBar.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/navigation/GlassNavigationBar.kt)、[`ModelAtlasApp.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/ModelAtlasApp.kt)。

- Release 包含“模型｜收藏｜对比｜设置”，Debug 为“模型｜收藏｜对比｜设置｜调试”，同一条目列表驱动分页与底栏；选中块、拖动定位和模型双击范围均按实际标签数量计算，不让非模型标签双击误触发回顶。胶囊底部居中，最大宽度 `400dp`，两侧至少留白 `16dp`，距离系统导航安全区 `16dp`；四栏标签水平内边距为 `8dp`、五栏为 `2dp`，保留字号与点击高度。
- Android 12 及以上显示玻璃采样与模糊，支持的平台进一步呈现折射；Android 10/11 和设计预览使用实色胶囊兜底。文字与选中态在兜底模式下仍须清晰可辨。
- 标签图标为 `24dp`，最小布局高度 `56dp`，大字体时自动增高；模型、设置与 Debug 调试图标均未选为描边、选中为实心；模型与调试图标切换时不改变外轮廓，调试图标使用小扳手，描边宽度与设置一致为 `1.8dp`。
- 点击标签、横向滑动页面或拖动导航均可切页；选中块连续跟随分页偏移，图标与颜色平滑过渡。
- 普通切页保留位置。双击“模型”平滑回到目录首项；从设置页双击则切页和回顶同时进行，不刷新或清除展开状态。
- 提供 Tab 单选语义，以及“回到模型列表顶部”的等效无障碍操作，不要求读屏用户依赖触摸双击。

## 5. 信息文案与数值

| 内容 | 展示约定 |
| --- | --- |
| 缺失字段 | “暂无数据”，不推断为零或不支持 |
| 模态集合 | 图标展示，读屏区分缺失“暂无数据”与明确空集合“无”；未知模态保留原文描述 |
| 开放权重 | “开放权重”“权重未公开”“开放权重：暂无数据”三态 |
| 权重许可 | 仅在权重公开且许可短名为 1–16 字符时附“· MIT”等原文；长名称不截断或猜测简称 |
| 发布时间 | 保留来源精度，不补全为虚构日期 |
| 卡片 token 限制 | 十进制 K／M、最多一位小数，如 `1M`、`384K`、`131.1K`；读屏提供完整精确值与 tokens 单位 |
| 筛选门槛 | 精确 K／M 缩写，如 `131.072K`，不沿用卡片近似值 |
| 价格档位门槛 | 带千位分隔的完整数值，如 `272,000` |
| 单价 | 至少两位小数，保留更高精度，如 `$0.60`、`$0.003` |
| 零价／缺失报价 | 明确零价为 `$0.00`；没有可用报价为“价格：暂无数据” |

“开放权重”不等于开源或允许商用；单字段零价不代表整个服务免费。相关说明集中在来源许可页面，不在卡片中新增未经数据支持的营销标签。

## 6. 状态与反馈

| 场景 | 界面行为 |
| --- | --- |
| 首次无本地目录、首次失败重试 | 搜索框、筛选按钮、已恢复的条件标签及排序说明保留等尺寸骨架占位，与六个惰性卡片骨架共享扫光；不创建运行时假模型 |
| 已有本地目录 | 立即展示真实内容，后台检查不打断浏览 |
| 真实空目录 | 空目录状态，不误显示无搜索结果 |
| 有目录但查询无匹配 | 无结果状态，保留查询入口，允许清除全部条件 |
| 首次加载失败 | 阻断错误状态卡片与重试操作 |
| 主动刷新 | 保留列表，只展示下拉刷新指示器，不叠加骨架或内联加载提醒 |
| 后台检查发现模型增删 | 页头下内联提醒，用户点击“立即更新”后应用 |
| 仅内容变化 | 静默更新，不显示待更新或成功提醒 |
| 主动刷新成功／无变化 | “模型目录已更新／已是最新数据”，无关闭按钮，约 3 秒后消失，遵循无障碍建议时长 |
| 主动刷新失败 | 非阻断内联错误，保留真实列表，提供重试或应用待更新快照及手动关闭 |
| 后台检查失败 | 静默保留本地目录，不打扰浏览 |

内联提醒使用 `24dp` 圆角、`16dp` 内边距与主题浅层容器色，正文和操作支持换行。提醒随列表滚动，不固定、不弹 Snackbar，不主动滚回顶部；消失后不残留间距，关闭错误不丢弃待更新快照。

实现：[`CatalogStatusNotice.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/modellist/CatalogStatusNotice.kt)、[`ModelCardSkeleton.kt`](../app/src/main/java/io/github/chenlongapps/modelatlas/ui/modellist/ModelCardSkeleton.kt)。状态流转细节见[架构说明](architecture.md#数据与状态流转)。

## 7. 动效、适配与无障碍

### 动效

- 内联提醒淡入 `200ms`、淡出 `180ms`，同时平滑调整高度和间距；不加弹跳或大幅位移，快速切换可中断并收敛到最新状态。
- 提醒退出时立即禁用旧操作、清除旧读屏语义，避免动画期间执行过时动作。
- 骨架共享 `1.2s` 扫光周期；页面隐藏或应用不在前台时暂停。系统关闭动画时显示静态骨架，不阻碍加载完成。
- 搜索与筛选骨架复用真实控件测量，只替换绘制，不额外展开高度；加载完成后原位恢复控件，避免首张卡片因查询区和排序说明突然插入而下移。占位期间禁用输入、清空、筛选和条件移除，不打开键盘或筛选面板，也不暴露对应读屏操作。
- 档位箭头旋转与内容高度平滑过渡；导航选中态和列表回顶保留连续动画，遵循系统动画时长设置。
- 列表与详情以约 `450ms` 的整卡容器变换衔接，类似从桌面打开应用：点击的卡片从原位置扩展为全屏详情，先快后慢、不弹跳；圆角由 `24dp` 连续收敛至 `0dp`，不透明底色由卡片 `surface` 过渡到页面 `surfaceContainerLowest`。背景目录及悬浮导航保持原样，由展开的容器逐步覆盖，不再整页淡出；列表条目保持原占位，不推移其他卡片。
- 整卡展开同时保留身份共享动画：Logo 从列表位置移动并由 `56dp` 等比放大至 `88dp`，模型名称、研发机构、权重标签各自移动边界并交叉淡化衔接字号、换行与对齐。身份与容器使用相同的 `450ms` 时长与缓动，在两端容器之上单独绘制，继承动态容器轮廓裁剪，不叠加父级缩放或局部内容淡化，也不重复显示身份。其余内容在最终约束下测量、按宽度等比缩放，以约 `120ms` 的局部淡化交接；不把文字或价格非等比拉伸。详情内部滚动标题、标签横滑及价格展开行为不变。
- 进入详情即用点击时的临时身份快照展示加载头部，本地查询完成后原位替换为真实详情，不重启动画；加载期间不补造描述、参数或价格。快照不持久化，错误或模型移除时不继续展示；恢复详情时只按已保存 ID 读取数据，不重播进入动画。返回时容器与身份一起反向过渡；详情已滚动时停用身份共享匹配，但仍将整个页面缩回原卡片，不自动滚回头部或移动目录；来源卡片消失或缺少容器匹配时才退化为 `180ms` 淡出。系统预测性返回实时寻址同一套共享过渡，取消从当前进度平滑恢复详情，确认只完成剩余收缩；暂停手势不清理页面，底层列表保持原状态且不能接收触摸、焦点或读屏。
- 退出页面在动画结束前保留布局，但立即屏蔽其触摸和读屏操作；详情完成退出时先停止绘制，再清理组合，避免共享层结束后短暂闪回全屏详情。主分页器持续组合，查询、列表位置、报价展开及提醒计时不因动画重置。入场中返回仍连续收缩，系统关闭动画时直接收敛至最终布局并清理详情。

### 布局与安全区

- 使用 edge-to-edge：系统时间、电量等信息保留，模型页状态栏区域使用半透明渐变保护，不绘制固定实色应用栏。
- 模型页将系统栏与显示缺口安全区合并到列表 `contentPadding`；初始内容避开系统图标，滚动内容仍可延伸到系统栏下方。
- 详情顶部安全区由固定返回栏避让，使用与页面一致的背景保护系统图标；列表视口从返回栏下方开始，滚动定位及读屏聚焦不会被栏遮挡。返回栏避让两侧显示缺口，列表侧边与底部安全区进入内容留白，统一消费 insets，避免重复避让。
- 列表底部额外避让实测导航高度与外边距；内容可经过玻璃后方，但最后一项及操作必须能滚到导航上方。
- 键盘打开时通过单次 IME 避让缩小列表视口，不重复添加键盘安全区；离开模型页关闭筛选面板并清除输入焦点。
- 参数、标签和价格按宽度及字号换行；支持 RTL 下的相对布局、方向图标与导航拖动映射。
- 当前是单列目录与顶层分页（Release 四栏，Debug 五栏），对比内容按可用宽度与字号适配；不将平板双栏目录、导航轨或折叠屏专用布局描述为已实现。

### 无障碍

- 标题、标签选中态和折叠状态提供对应语义，图标按钮提供操作名称；装饰性图标与重复 logo 不增加冗余读屏节点。
- token 缩写不减少读屏精度；仅图标模态标签仍提供输入／输出方向及模态描述。
- 加载骨架只提供一个礼貌级加载与不确定进度节点，其余占位不重复朗读或提供操作。
- 内联状态使用礼貌级更新语义，成功提示的停留时间遵循无障碍服务建议。
- 紧凑视觉元素与触摸区域分开处理，尤其保留价格档位标题至少 `48dp` 的实际触摸高度。
