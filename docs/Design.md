# ModelAtlas UI/UX 设计规范

本文维护当前视觉与交互，不是改版规划。字段只在[页面字段](page-information.md)维护，生命周期／状态实现见[架构](architecture.md)，任务与验收看 [TODO](../TODO.md)。

## 设计原则

- 紧凑、易扫读：突出身份、关键参数和单价，以字号、语义色及留白分层，不堆装饰卡片。
- 紧凑不牺牲可用性：完整名称／精确价格优先换行，窄屏大字号不缩字、不裁切、不减少触摸区域。
- 保持连续性：刷新失败不清已有目录，普通切页保留位置／查询／展开，加载不夹回正文位置。
- 主题一致：Material 3 语义色，明暗与颜色来源独立，不复制参考图固定配色；品牌素材保留原色白底。
- 不误导：未知不补造、不把开放权重叫开源，不用视觉强调暗示最低价、质量胜负或同配置公平排名。

## 视觉基础

### 颜色与主题

主题入口为 `ui/theme/Theme.kt`，外观优先级与持久化见[外观设置](appearance-settings.md)。预览关闭动态取色，稳定颜色测试使用 `ModelAtlasTheme(dynamicColor = false)`；动态色另验收。

| 角色 | 用途 |
| --- | --- |
| `surfaceContainerLowest` | 页面背景 |
| `surface` | 模型／评测卡片、筛选面板 |
| `surfaceContainerLow` | 搜索框、普通信息标签、内联提醒、设置区块 |
| `onSurface` / `onSurfaceVariant` | 正文／次要信息 |
| `primary` | 研发机构、价格与评测重点分数、选中强调 |
| `secondaryContainer` / `onSecondaryContainer` | 已应用条件与活动筛选入口 |
| `tertiaryContainer` / `onTertiaryContainer` | 开放权重状态标签 |
| `outlineVariant` / `error` | 低对比分隔线／错误强调 |

### 字体与尺寸

沿用 Material 3 Typography 和系统缩放；主题将 `headlineMedium`、`titleLarge`、`titleMedium` 默认设为 SemiBold。

| 内容 | 字体／尺寸 |
| --- | --- |
| 应用／设置大标题、详情大模型名 | `headlineMedium` |
| 筛选标题／说明页标题 | `headlineSmall` / `titleLarge` |
| 模型／评测名、核心单价／总览成绩 | `titleMedium`，单价与总览成绩局部 Bold |
| 正文／次要参数／信息标签 | `bodyMedium` / `bodySmall` / `labelMedium` |
| 价格标题及单位 | `labelSmall`（默认 11sp / 16sp） |
| 主题圆角 small／medium／large／extraLarge | 10／16／24／32dp |
| 模型卡片圆角／内边距／卡片间距 | 24／16／16dp |
| 页面水平留白／内容组间距 | 安全区外 16dp／通常 12dp |
| LAB Logo 底座／内部图形／圆角 | 列表 56／44／14dp，详情底座 88dp、等比放大 |
| 参数／模态图标，方向箭头 | 16dp，箭头 18dp |
| 非交互标签圆角／水平／垂直留白 | 10／8／4dp |
| 搜索框／筛选底部按钮最小布局高度 | 56dp |

数值与文案口径见[通用字段规则](page-information.md#通用规则)，这里不重复维护舍入、单位或空值语义。

## 核心组件与页面交互

### 模型目录与卡片

- 页头、内联提醒、搜索、排序说明均随列表滚动，不使用固定／吸顶 TopAppBar。目录末尾避让实测悬浮栏；普通切页保留位置，双击模型导航才回顶。
- 卡片结构：横排身份 → 可换行图标参数 → 输入到输出模态 → 细分隔线 → 价格。收藏书签放身份末端、与名称顶对齐，不另占行。
- 卡片整面 `surface`、无内层价格背景／圆角／额外缩进；整卡无涟漪，保留明确“查看模型详情”语义。价格标题独立处理档位，不触发详情。
- 价格输入／输出／缓存命中按实际宽度和字号使用 1–3 列，列间细线；其他单价逐行。标题到指标 4dp，指标内部 2dp，换行 8dp，不截断／近似报价。
- 档位标题布局随内容约 16dp、箭头 16dp，由 `clickable` 扩展至少 48dp 触摸高度，附近不放冲突操作；不以 48dp 布局最小高度重新撑开。收起向下、展开向上，整行操作，无档位无箭头。
- 信息标签非交互，不借用 FilterChip 暗示可点；仅图标模态仍给读屏完整方向与名称。

### 搜索与筛选

- 无描边填充胶囊搜索框，清空独立，键盘搜索键收起键盘；入口在框下，显示图标、条件数、箭头。条件标签可移除并换行；外部“重置”保留搜索，无结果“清除全部”才清搜索与筛选。
- 面板顶部圆角 32dp、水平留白 20dp、分组 24dp；标题／匹配数在上、分组滚动、底部固定等宽重置／应用（56dp 高，间隔 12dp）。不另放关闭图标，应用不显示重复条件数。
- 普通字号约用可用高度 75%，`fontScale > 1.5` 提至 90%。选项为浅色胶囊，选中主题色 1dp 描边及淡底；模态保留图标。
- 只编辑草稿，应用才提交；遮罩、下滑、系统返回放弃。LAB 默认最多八项、已选始终可见，超过提供更多／收起，刷新后失效选项仍能取消。计数／排序／恢复细节见[查询架构](architecture.md#查询与反馈)。

### 品牌素材

- LAB、服务商、评测三套映射独立，随包加载不联网；无素材中性兜底，不借相似品牌。保持完整画布与宽高比、原色白底，RTL 不镜像图案，邻近文字已有名称则 Logo 不重复读屏。
- LAB 按规范 ID 前缀，名称用品牌惯用写法，未知保留原文；它不是独立核实的开发商认定。
- 服务商 `ProviderLogo` 按稳定服务商 ID 精确匹配，底座 40dp、内部 32dp、圆角 10dp，距名称 12dp；列表／对比不增加服务商 Logo。来源／转换边界见[数据来源](data-source.md#数据许可与来源署名)。
- 评测 Logo 按定义 ID 精确匹配，宽字标用宽底座，来源、摘要及描摹边界见[评测 Logo](benchmark-logos.md)。

### 模型详情

- 独立全屏，固定返回栏避让安全区，公共身份与标签随正文滚动。88dp 居中 Logo／完整模型名／机构／权重，描述左对齐，方向模态与已支持能力居中；背景直接沿用页面，不加渐变、大卡或重复参数卡。
- 返回栏品牌与紧凑模型名按大标题实测位置连续交接；最多 8dp 位移，两层始终测量、不改栏高。紧凑层可单行省略、读屏保留全名，交接只暴露一份标题。
- 常规三个标签等宽，放不下可横滚，完整文字与至少 48dp 触摸高度。只有标签正文横向分页，公共区域不横移；标签点击／滑动、RTL 和独立阅读恢复一致。
- 概览三张轻量卡：24dp 圆角、20dp 内边距／组间距，主题描边标题图标，不嵌套指标小卡或彩色圆形装饰。
- 技术参数突出上下文／最大输出：`headlineSmall` 半粗精确数值、tokens 单独一行，上下文 `primary`；缺失用次要色 `bodyMedium` 且无单位。最大输入／两项参数量为次级信息，日期在淡分隔线后双列页脚。列间 24dp，按完整数值／单位实测，放不下或不足 `240dp × fontScale` 则逐组单列。
- 模态固定输入／输出上下两行，标签共用实测至少 40dp 列宽、与内容相距 20dp、行间 20dp，图标＋文字只在内容列流式换行，无内层底、箭头或灰显推测项。
- 权重用既有非交互状态标签，下方完整许可摘要，不重复字段标题／图标／分隔线；长文完整换行。
- 价格轻量卡 24dp 圆角、16dp 留白，顶部 Logo＋服务商／完整服务 ID，下方上下文／最大输出／输入／输出四列。`labelSmall` 标签、`titleSmall` 半粗值，价格 `primary`；实测宽度整组降为两列／单列、间距 12dp，不画网格、装饰图标或无操作箭头。卡内不显示 tokens 后缀，精确读屏语义仍保留；价格单位列表顶部统一显示。
- 评测轻量卡同为 24dp／16dp，顶部 Logo／完整名称／重点分数，下方已有条件和说明；实测不足分数下移，不缩字。可比性提示一行正文而非独立卡；显示字段与排序见[详情字段](page-information.md#模型详情页)。

### 评测榜单

- 总览复用模型 `Card` 的 `surface`／24dp 圆角／16dp 留白，内容组和成绩项间 12dp，无描边、额外阴影、箭头或涟漪；整卡明确“查看完整排行榜”按钮角色。
- 顶部 Logo／`titleMedium` 名称起始侧顶对齐；总览 Logo 底座普通 56×56dp、宽字标 88×56dp、圆角 14dp、内留白 6dp，不改变详情 Logo。
- 每项 `bodyMedium` 普通模型名与末侧 `titleMedium` Bold／`primary` 成绩同排，下方 6dp 通栏柱条，文字到柱条 8dp；实测不足分数下移末侧，不挤窄或截断模型名（含推理档位）。
- 机构品牌色不随名次变化，颜色／柱条仅辅助，读屏提供名次、模型、显示分数／完整单位及档位；总览另保留版本／指标和精确轴范围，不能只用颜色传递信息。
- 完整榜单简介常规字号最小约 64dp，40dp 高 Logo＋完整名称／版本／类型，可随字号增高；按文字实测不足时，Logo／信息按钮在上、名称及版本／类型独占下方整行，避免宽字标挤窄长版本。说明仅非空时用至少 48dp 信息按钮打开可滚动弹窗，支持关闭／遮罩／系统返回及重建恢复，不改变正文位置。
- 页头轻提示集中说明最高成绩／配置不同／局部刻度，不重复副标题。两页不显示可视刻度栏；展示范围与未参榜成绩边界见[页面字段](page-information.md#评测页与完整排行榜)。
- 总览整卡与全榜约 450ms 展开／缩回，24dp 圆角到 0、卡片到页面底色连续；Logo／名称及前三名的模型名／分数／轨道／填充同步交接，返回栏与其他正文局部淡入，背景总览不整页淡出。文字不含整列留白、不异常放大，分数不做计数动画；条高 6→8dp、长度按两页各自刻度过渡到真实目标比例，不统一坐标轴或修改成绩。名次、全榜单项背景及第四名之后不共享。支持预测性拖动／取消／确认、零动画；滚动后仅保留整卡返回，不强制回顶。键、布局保留与清理规则见[评测转场架构](architecture.md#评测卡片与排行榜共享转场)。

### 收藏

- 唯一操作在详情固定栏右侧，书签描边／实心外轮廓一致，提供名称及状态语义；保存中禁用。收藏成功停留，取消持久化成功后返回，无二次确认，失败保留状态提示。
- 可用收藏复用模型卡，不可用只显示历史身份／不可用状态；不提供独立导航页，不显示旧参数／报价。来源暂留卡不可交互或读屏；重排／淡出等转场交接规则见[架构](architecture.md#收藏的数据与状态)。

### 双模型对比

- 顶层页无返回按钮，保留底栏；顶部两轻量选择卡间隔 12dp、不放 VS／重复权重。并排按名称／机构各自最大实测高度动态等高、对齐更换操作，不限名称行数，替换可回落；上下排列不共享高度。
- 正文圆角分组、淡横线、16dp 列间留白，无竖线。手机用字段在上双值在下；分区宽度达 `600dp × fontScale` 用字段＋双值三列，低于 `240dp × fontScale` 上下排列并重复模型名。并排分区用双模型名列头，不新增模型名称字段。
- 服务 ID／完整许可／档位展开提供至少 48dp 明确动作及状态语义；值完整换行、恢复后保留，替换重置。选择面板关闭不变更选择，另一侧已选禁用。
- 读屏逐项带模型名、字段和精确值；不加价格胜负、性价比进度条或任务能力推断。字段归[对比表](page-information.md#对比页)，异步恢复归[架构](architecture.md#双模型对比的数据与状态)。

### 设置与 Debug

- 设置入口／说明块留白 20dp；子页固定安全区返回栏、可滚动正文，隐藏主界面交互与读屏，返回恢复位置。外观网格随宽度／字号 2–4 列，明暗不够则纵排，预设可不显示名称但读屏有名称／选中态；交互细则见[外观设置](appearance-settings.md)。
- Debug 为第五顶层页，沿用滚动大标题与主题分区，无返回设置按钮；字段完整换行，未知统计不显零、读取失败标明旧值，末尾避让实测底栏。
- 数据库管理全屏逐层返回，未保存草稿确认放弃，可空与类型明确，敏感列默认隐藏；键盘、窄屏大字号及 RTL 均须可用。删除及安全边界见[本地数据](local-data.md#debug-数据库管理)。

### 悬浮底部导航

- Release 四栏／Debug 五栏，按实际数目与 RTL 布局。底部居中、最大宽 400dp、两侧至少 16dp、距系统导航安全区 16dp；图标 24dp、标签最小布局高度 56dp，大字号自动增高。
- 当前支持 API 33+ 的玻璃采样、模糊／折射，设计预览实色兜底；不将遗留低版本渲染分支视为仍支持 Android 10/11 安装。
- 点击、横向分页或导航拖动切页，选中块连续跟随偏移，图标描边／实心、颜色平滑变化，模型双击平滑回顶不刷新。
- 向下浏览实际累计 12dp 隐藏，反向 12dp／顶部外拉恢复，200ms 可中断动效遵循系统倍率；惯性、程序滚动、弹层不驱动，短内容不隐藏。横向切页恢复，详情返回保留来源状态，重建默认显示。
- 隐藏位移包含整个导航及系统底部安全区，留白不变；隐藏目标立即禁点击／拖动／双击／焦点／读屏。真实触摸探索开启保持显示，提供 Tab 单选与等效回顶操作。

## 状态与反馈

| 场景 | 行为 |
| --- | --- |
| 首次无目录／首次重试 | 查询控件及排序说明等尺寸占位＋六卡骨架，不显示虚假零数量，无输入／操作语义 |
| 已有目录／主动刷新 | 保留内容，刷新只显示下拉指示器，不叠骨架或内联加载 |
| 空目录／无匹配／首次失败 | 分别给状态与正确重置／重试入口 |
| 启动后台同步／停留列表 | 展示缓存；所有变化静默写库，本次列表内容、数量、顺序及阅读状态不变，无确认提示 |
| 主动成功／无变化 | 简短结果无关闭按钮，约 3 秒、遵循无障碍建议时长 |
| 主动失败／后台失败 | 前者非阻断提醒，可重试及手动关闭；后者静默保留数据 |

内联提醒仅显示主动刷新反馈，优先级为刷新错误 → 更新结果，刷新中隐藏；24dp 圆角、16dp 留白、语义浅底，操作支持换行，礼貌级更新。随列表滚动，不弹 Snackbar、不主动回顶；淡入 200ms／淡出 180ms＋高度过渡，退出立刻禁旧操作／读屏，结束无空白。骨架共享 1.2s 扫光，离屏／非前台／禁用动画时静态。

## 动效、适配与无障碍

- 整卡打开／返回约 450ms，24dp 圆角到 0、卡片到页面底色连续，不弹跳、不整页淡出背景目录。Logo 56→88dp，身份与容器同步，正文等比缩放局部淡化；预测性返回暂停／取消／确认同轴，具体交接只在[架构](architecture.md#共享容器与返回交接)维护。
- 系统关闭动画直接收敛并清理，旧页面退出立即禁操作，主 Pager 与查询／阅读状态不重建。
- edge-to-edge 保留系统图标，以不占布局／不拦触摸的主题半透明状态栏渐变保护；列表用系统栏／刘海 `contentPadding`，内容可滚入安全区，最后操作能滚至底栏上方。
- 详情返回栏承担顶部安全区，正文统一消费其余 insets，单次 IME 避让缩小视口，不重复 padding；RTL 使用相对起止布局及正确拖动方向。
- 当前单列目录／顶层 Pager，不将导航轨、平板双栏或折叠屏专用布局写成已实现。
- 标题、选中、折叠提供标准语义；装饰图标不重复朗读；骨架只有一个礼貌级加载节点。完整信息、实际触摸区域及无障碍操作优先于固定高度。

## 修改后检查

仅为检查清单，不表示执行过验收；选测按[测试说明](testing.md)，未验收看 [TODO](../TODO.md#待验收与发布)。

- 浅／深／动态色，品牌原色白底；320dp、双倍字号、RTL 完整换行。
- 缺失／空／零／能力三态、精确单价与读屏不混淆，触摸区域不缩小。
