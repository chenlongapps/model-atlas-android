## UI 设计一致性与修改约束

本文件是 ModelAtlas 的 UI/UX 设计契约。所有新增页面、组件及视觉、交互修改均须遵守。

### 设计目标

- 遵循 Android Material Design 3 的设计理念、组件语义和无障碍要求。
- 保持与当前 ModelAtlas 主界面一致的视觉语言。
- 以简洁、紧凑、信息优先为核心，不为装饰牺牲内容可读性。
- 新功能融入已有设计体系，不独立创造另一套界面风格。
- 不因为局部 UI 需求而擅自重新设计整个应用。

### 规范优先级

1. Android 平台行为、可访问性与基本可用性要求。
2. Material 3 的主题、组件语义及交互原则。
3. 本文明确规定的 ModelAtlas 视觉与交互规则。
4. 当前已实现的主要页面和共享组件。
5. 外部设计参考、第三方示例及 AI 自行提出的设计方案。

Material 3 允许的自定义设计不应被错误地替换成默认样式。

现有实现与本文冲突时，必须先识别冲突并说明处理依据，不得默默改变全局风格。

### 现有设计基准

修改 UI 前，应先阅读相关实现，而不是仅凭文字生成界面。

- 全局主题：`ui/theme/Theme.kt`
- 模型列表卡片：`ui/modellist/ModelCard.kt`
- 搜索与筛选：`ui/modellist/ModelCatalogControls.kt`
- 评测总览卡片：`ui/benchmark/BenchmarkCard.kt`
- 模型详情：`ui/modeldetail/ModelDetailScreen.kt`
- 详情概览：`ui/modeldetail/ModelOverview.kt`
- 设置页面：`ui/settings/SettingsScreen.kt`
- 底部导航与聊天输入栏：`ui/navigation/GlassNavigationBar.kt`、`ui/navigation/MorphingBottomBar.kt`

优先参考与目标页面功能相近的现有组件。

新页面的容器、留白、字体层级、颜色和交互状态应与这些基准一致。

### Material 3 实现约束

#### 主题与颜色

- 优先使用 `MaterialTheme.colorScheme` 中的语义颜色。
- 不为普通 UI 元素硬编码固定颜色。
- 不复制截图中的颜色来替代主题色。
- 兼容浅色、深色、动态配色及应用自定义配色。
- 品牌 Logo 保留既定原色与底座设计。
- 不擅自调整全局 ColorScheme、Typography 或 Shapes。

#### 字体与形状

- 使用 `MaterialTheme.typography` 中的文本样式。
- 优先使用 `MaterialTheme.shapes` 中的既定形状。
- 遵循本文现有的间距和圆角规范。
- 不为每个页面单独创建新的视觉尺寸体系。
- 完整数据优先于固定高度与单行显示。

#### 组件与交互

- 优先使用 Compose Material 3 官方组件。
- 当已有组件满足需求时，优先复用已有组件。
- 自定义组件必须遵循 Material 3 的状态、语义和交互原则。
- 不随意替换现有底部导航、搜索框、筛选面板和卡片体系。
- 不为装饰引入多余卡片、阴影、渐变、描边及复杂动效。
- 所有交互目标应具有足够的可触摸区域，通常至少 48×48dp。
- 支持键盘、TalkBack、RTL、系统返回和字体缩放。

### UI 修改执行流程

每次新增或修改 UI，必须依次完成以下阶段。

**阶段一：理解现状**

1. 阅读本文中与目标页面相关的章节。
2. 阅读 `Theme.kt` 和目标页面现有实现。
3. 检查功能相近的已有页面和组件。
4. 明确本次修改范围，识别应保留的现有设计。

**阶段二：确定方案**

1. 优先复用现有组件、主题角色和排版方式。
2. 检查方案是否符合 Material 3。
3. 检查方案是否与主要页面的视觉语言一致。
4. 仅在确有必要时增加新的组件或设计规则。
5. 如果需要改变全局设计体系，明确提出变更，不作为局部任务的附带修改。

**阶段三：实现**

1. 仅修改本次任务必要的 UI。
2. 不因局部需求重构无关页面。
3. 不引入与现有设计冲突的颜色、圆角或间距。
4. 保留现有导航、动画、状态及无障碍行为。
5. 使用已有 Material 3 组件和设计令牌。

**阶段四：验证**

1. 验证浅色、深色及动态配色。
2. 验证窄屏、大字体及 RTL。
3. 验证触摸区域、文本换行与内容完整性。
4. 验证加载、空状态、错误和正常状态。
5. 与对应的现有页面或组件预览进行视觉比较。
6. 按修改范围执行相关测试，并如实记录未验证项目。

### 设计变更边界

- 局部页面调整不得自动扩展为全局改版。
- 公共组件修改必须评估所有使用位置。
- 不得以“更现代”“更美观”为由覆盖现有设计。
- 不得因为新的 Material 3 示例而自动迁移既有组件。
- 现有设计存在实际可用性或无障碍问题时，应优先修复问题，同时尽量保留原有视觉语言。

### UI 任务交付要求

完成 UI 修改后，必须简要报告：

- 修改了哪些界面和组件。
- 复用了哪些现有设计规则。
- 是否符合 Material 3，是否存在有意的自定义差异。
- 是否改变了全局风格或公共组件。
- 实际完成了哪些预览、测试和视觉检查。
- 有哪些未验证事项或剩余风险。

不得将未执行的检查报告为已通过。

### AI 助手

- 底部采用「起始侧胶囊导航＋末侧独立圆形 AI 入口」，LTR 为左胶囊右圆，RTL 镜像。胶囊保留 Release 四项／Debug 五项与单选指示器；AI 入口显示 `AI`，读屏名称为「AI 助手」，语义是打开助手的按钮，不是 Tab。模型仍为默认首页；助手不属于主 Pager，不参与左右横滑。
- 点击 AI 入口后，共享底栏作为同一个玻璃容器留在原位置：胶囊内容交叉淡化为多行输入栏，右侧圆形入口淡化为发送／停止，主页面过渡到 Navigation 3 全屏助手路由。容器外框、圆角、水平起止与玻璃表面保持不变，仅高度随内容自然增长；模式切换约 200–300ms，退出端内容立即禁用交互与读屏，动画期间不能出现两套可操作底栏。
- 助手路由不重建底栏。输入栏直接绑定 Activity 作用域 `ChatViewModel` 的草稿、发送与停止状态，不维护第二份输入状态；发送禁用条件仍为未配置有效 API、输入为空或正在生成，生成期间右侧入口显示停止。输入支持多行，默认单行高度与导航胶囊一致，达到上限后在编辑器内部滚动；胶囊高度随内容变化，返回导航模式时平滑收缩。
- 聊天模式的输入区不响应主导航拖动切页与模型双击；胶囊仅作为编辑器容器。键盘出现时输入栏位于键盘上方，消息区同时收缩并为输入栏留白；系统返回与页面返回按钮都先收键盘，无键盘时再 pop 回进入前的原页。
- 助手提供返回按钮，右上角保留会话配置，标题下显示当前模型或配置状态，设置不再重复展示入口。安全区内可用高度低于 400dp 时标题参与消息区滚动，返回与配置入口固定在消息区上方；输入栏仍由共享底栏提供，页面内不再放第二个编辑器。
- 使用 `ModelAtlasTheme` 的语义色、Typography 和 Shapes。背景沿用 `surfaceContainerLowest`，页面横向留白以 16dp 为主；标题使用 `headlineMedium`，正文使用 `bodyLarge`／`bodyMedium`，辅助信息使用 `bodySmall`／`onSurfaceVariant`。不调整全局主题或其他页面样式。
- 空会话使用简洁欢迎语、能力边界说明及三个可换行问题入口；入口采用主题 `surfaceContainerLow`、16dp 圆角和至少 48dp 高度，点击仅填入共享输入栏，不自动请求。
- 用户消息末侧对齐，复用 `secondaryContainer` 和 16dp 圆角；助手回复起始侧对齐，以正文为主，不给每条回复再套装饰卡片。复制、失败、停止与显式重试保留清晰可访问的操作和说明，长文本不截断。
- 共享输入栏复用导航胶囊的玻璃材质、主题语义色和圆角，水平内边距 20dp，占位提示使用 `onSurfaceVariant`；右侧发送／停止入口保持至少 48×48dp 与完整语义，并在 AI、发送、停止三种状态间淡入淡出。输入栏最大高度受限，长输入内部滚动；RTL 时胶囊与入口随 Row 自动镜像。
- 助手路由不额外预留主导航高度，消息区为共享输入栏的实测高度加间距留白；输入栏由外壳跟随 IME 定位，页面自身消费安全区与 IME。配置弹窗／确认窗口优先处理返回；预测性返回使用 Navigation 3 内置过渡，取消不离页或停止生成，确认才停止并返回。
- 主界面两个容器沿用既有玻璃效果及主题语义色，不修改全局主题。AI 圆形入口在主路由显示、无选中状态，聊天路由中同一位置切换为发送／停止；胶囊保留来源页面的单选指示，其内容在助手路由交叉淡化为编辑器，不包含助手空位或专用淡入／淡出映射。
- Release 胶囊为「模型／评测／对比／设置」四项，Debug 追加「调试」。圆形入口常规直径 64dp、紧凑时缩至 48dp，位于胶囊末侧并间隔 8dp；胶囊内边距 4dp，四项间距 4dp、五项间距 2dp。Debug 外侧边距 4dp，320dp 窗口时为 256dp 胶囊＋8dp 间隔＋48dp 圆形，五项各至少 48dp。大字号标签可换行，不压缩字号或缩小触摸区域。
- 保留胶囊拖动切页与模型双击回顶，拖动只命中胶囊项；AI 点击也会打断模型双击序列。主界面整组底栏共同滚动显隐及子页隐藏，并按整个分体底栏的实测最大高度避让。胶囊为单选 Tab 组，AI 为独立按钮，键盘与读屏可以访问全部入口；聊天模式隐藏的导航内容不进入读屏树。
- 退出助手时输入栏淡回导航胶囊、发送／停止恢复 AI 入口，保留内存对话、输入草稿和阅读位置，但停止未完成回复；再次打开不自动续发、不自动唤起键盘。返回原主路由时恢复来源页、列表位置及展开状态，不发起新的目录刷新。离屏页不拦截返回、不弹配置窗口、不触发请求。流式增量保持既有文字锚点与末尾跟随规则，具体状态契约见[聊天](chat.md)。
