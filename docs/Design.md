# UI/UX 设计规范

本文维护视觉、布局与交互契约；显示字段见[页面字段](page-information.md)，状态与转场实现见[架构](architecture.md)。新增和修改 UI 均须遵守。

## 原则与一致性约束

- 简洁、紧凑、信息优先；完整数据优先于固定高度或强制单行，不为装饰增加卡片、阴影、渐变、描边或复杂动画。
- 优先级：Android 平台／无障碍 → Material 3 语义 → 本文规则 → 现有共享组件 → 外部参考。Material 3 允许的自定义不应被默认样式替代。
- 复用 `ModelAtlasTheme`、现有组件及尺寸体系。普通 UI 使用 `MaterialTheme.colorScheme`、`typography`、`shapes`，不照截图取色；兼容浅／深、动态色和自定义色，品牌保留原色与既定底座。
- 局部任务不附带全局改版、无关页面重构或组件迁移；公共组件变更须评估所有使用位置。全局 ColorScheme／Typography／Shapes 变更须明确提出。
- 交互区域通常至少 48×48dp；支持键盘、TalkBack、RTL、系统返回和字体缩放。可用性问题优先修复，同时尽量保留既有视觉语言。
- 规范与实现冲突时先说明依据，不以“更现代”、新示例或 AI 建议默默覆盖现有风格。

## 修改流程与验证

1. 先读本页对应章节、`ui/theme/Theme.kt`、目标实现和相近组件。涉及启动或系统栏时同时检查 `values/themes.xml` 和 `values-night/themes.xml`。
2. 按影响检查浅／深／动态色、窄屏／大字／RTL、触摸目标和文字换行，以及加载／空／错误／正常态。选测见[分级测试](testing.md)；交付时区分实际检查与未验证项。

## 状态与反馈

- 首次无数据才用骨架；空目录、无匹配、读取失败分别反馈，不用假模型填充。
- 主动刷新显示内联结果／错误，后台同步不打断浏览、不显示更新确认。提示与页头保持稳定列表身份；成功提示计时不随条目回收重置，替换提示时取消旧计时。
- 刷新失败保留正文且可重试；取消不报错。持续本地观察失败的清理规则见各页面[状态契约](architecture.md)。
- 动画遵循系统倍率与降低动画设置；骨架在非前台、离屏或禁用动画时静态，无额外加载延时。

## 悬浮底部导航

- 主路由为起始侧导航胶囊＋末侧圆形 `AI` 按钮，RTL 镜像。Release 为“模型／评测／对比／设置”，Debug 追加“调试”；模型默认首页。胶囊为单选 Tab 组，AI 是独立按钮，读屏为“AI 助手”，无选中态、不占 Pager 页。
- 圆形入口常规直径 64dp、紧凑时 48dp，与胶囊间隔 8dp；胶囊内边距 4dp，四项间距 4dp、五项 2dp。Debug 外边距 4dp：320dp 窗口下为 256dp 胶囊＋8dp 间隔＋48dp 圆形，五项各至少 48dp。大字可换行，不缩字号或触摸区。
- 保留胶囊拖动切页、模型双击回顶及等效无障碍操作；拖动只命中胶囊项，AI 点击中断双击序列。
- 自动隐藏默认关闭；开启且触摸探索关闭时，主页面实际向下滚动累计 12dp 隐藏整组底栏，反向滚动或横向切页恢复，显隐 200ms。关闭立即恢复并清累计值，不改阅读位置或底部留白。
- 隐藏时屏蔽触摸、焦点与读屏。主页面按整组实测最大高度＋32dp 留白，不随显隐变化；子页隐藏和助手输入栏不受自动隐藏开关影响。滚动消费与状态保存见[架构](architecture.md#顶层分页与子页面)。

## 模型详情

以下为现有详情布局约束；显示字段与排序以[页面字段](page-information.md#模型详情页)为准，状态／转场以[架构](architecture.md#模型详情的数据与导航)为准。

### 概览

- 专用排版在 `ui/modeldetail/ModelOverview.kt`，保留技术参数、模态、权重许可三张轻量圆角卡片，不嵌套指标小卡或彩色圆形图标。
- 技术参数突出上下文／最大输出，精确值与 tokens 分层；最大输入／参数量为次级信息，日期放在分隔线后的双列页脚。实测宽度不足或大字号时逐组降为单列。
- 模态固定为“输入／输出”上下两行，起始侧标签对齐，末侧图标＋文字换行；无箭头，仅列来源已有项。
- 权重复用非交互状态标签，完整许可放在下方摘要。只改概览时不影响公共头部、服务卡片或评测共用字段；配色使用主题语义色。

### 价格与评测卡片

- `ui/modeldetail/ModelServiceCard.kt` 顶部为 Logo／服务商／完整服务 ID，名称完整换行；底部上下文／最大输出／基础输入／输出价四列，按实测标签与精确原值宽度降为两列或单列，价格单位在列表顶部统一显示。
- `ui/modeldetail/ModelBenchmarks.kt` 使用轻量卡片，展示 Logo／完整名称／分数和明示单位，以及已有条件与说明；分数按实测宽度下移，不截断或换算单位。品牌图原色白底，宽字标等比完整显示，映射与维护见[评测 Logo](benchmark-logos.md)。

## 评测榜单

- 总览整卡可点击，Logo／完整名称在上，至多三项名称／分数及通栏柱条在下；空间不足时分数下移，不截断名称。可见字段与单位见[字段表](page-information.md#评测页与完整排行榜)。
- 总览 Logo 为白底、14dp 圆角、6dp 内留白，普通 56×56dp、宽字标 88×56dp；详情／全榜沿用各自底座，完整等比显示，映射见[评测 Logo](benchmark-logos.md)。
- 全榜简介最小高度 64dp，名称完整；宽字标或长文字放不下时独占文字行。信息入口至少 48dp，说明用可滚动弹窗，不常驻正文。
- 柱条使用机构色，针对背景保证至少 3∶1 对比，不按名次换色；局部刻度不冒充绝对能力比例。排名、坐标及共享转场见[架构](architecture.md#评测总览与完整榜单)。

## 双模型对比

- 依次展示紧凑的模型选择卡、关键规格、API 价格、评测摘要、基本信息、能力特性与权重许可。未选满时用槽位直接引导，不另设提示卡。正文除评测外仅保留分组标题，无外层卡片或行分割线。
- 各组共用参数行：手机端名称在上、等宽等高的值框在下，与模型槽位对齐；宽屏可将名称移至起始侧。值框用 `surfaceContainerLow`、主题 16dp 圆角、至少 48dp 高，内容居中并可完整换行。窄屏或大字时改为带槽位标签的纵向布局；并列时 RTL 镜像，读屏保留模型名称与字段上下文。
- 评测分数沿用评测卡：复用详情 Logo，按槽位上下展示模型名称、分数及通栏机构色横条，长名称与分数按宽度换行，RTL 镜像。条长共用零基准；明示百分制用 0–100，不展示刻度标签。任一成绩为文本时不绘制横条。
- 规格使用单一语义的「仅看差异」开关；已确认的不同值对称加粗，缺失值保持中性。不标报价高低或评测胜负；无可展示成绩时用一行空态。
- 有报价或参考评测成绩时，相应分区提供 48dp 信息按钮和可滚动说明弹窗；说明不常驻正文。弹窗可用「关闭」或系统返回退出，离开对比页或更换模型时关闭。
- 展开态两侧居中展示 56dp LAB Logo、完整名称、研发机构和「更换」，不显示 VS。吸顶态每侧为小 Logo、完整名称和下箭头；整侧可点击，已选槽位可在对应选择面板中移除。候选复用 LAB 身份与本地搜索。字段见[字段表](page-information.md#对比页)，选择及恢复见[架构](architecture.md#双模型对比的数据与状态)。
- 对比内容就绪后，标题随正文滚出，选择区按滚动距离连续收起，吸附到状态栏下方；滚回顶部时反向展开。按紧凑态内容高度判断，吸顶会占用一半以上可读高度或使正文不足 144dp 时，展开态随列表滚动。未选满、加载或失败时不吸顶，保留选择与重试入口。

## 设置与 Debug

- 沿用现有轻量圆角表面和语义色；自动隐藏开关在外观入口后，Material 3 Switch 整行单一语义、至少 48dp 高，文字完整换行。
- 外观网格用实际色板和选中标记，不展示预设色名；自定义取色器仅标题、关闭和单色相滑块。操作及失败规则见[外观设置](appearance-settings.md)。
- Debug 沿用设置视觉，不改变全局主题；入口／字段见[字段表](page-information.md#调试页仅-debug)，编辑安全边界见[本地数据](local-data.md#debug-数据库管理)。

## AI 助手

### 共享底栏

- AI 打开 Navigation 3 全屏路由。同一玻璃底栏留在原位：胶囊内容交叉淡化为编辑器，圆形入口淡化为发送／停止；外框、圆角、水平起止和玻璃表面连续，仅高度随内容变化，切换约 200–300ms。
- 不重建底栏、不放第二套编辑器；退出内容立即禁用交互与读屏，不能出现两套可操作底栏。导航指示器仍对应来源页，无助手空位。
- 输入栏绑定同一 `ChatViewModel` 状态，不存第二份草稿；未配置、空输入或生成中禁用发送，生成时圆形入口为停止。聊天模式不响应导航拖动／双击。
- 输入栏水平内边距 20dp，占位色 `onSurfaceVariant`；默认单行高度与导航胶囊一致，多行自然增长至上限后内部滚动，返回导航时平滑收缩。发送／停止至少 48×48dp，RTL 镜像。
- 输入栏由外壳跟随 IME，页面消费安全区与 IME，消息区收缩并按实测输入栏高度加间距留白，不额外预留主导航高度。

### 页面与消息

- 返回按钮与右上会话配置常驻，标题下显示当前模型／配置状态；设置页不重复入口。安全区可用高度低于 400dp 时标题随消息滚动，返回／配置固定在消息区上方。
- 背景 `surfaceContainerLowest`、横向留白以 16dp 为主；标题 `headlineMedium`，正文 `bodyLarge`／`bodyMedium`，辅助 `bodySmall`／`onSurfaceVariant`。
- 空态为欢迎语、能力边界和三个可换行问题入口；入口 `surfaceContainerLow`、16dp 圆角、高至少 48dp，点击仅填草稿，不请求。
- 用户消息末侧对齐、`secondaryContainer`、16dp 圆角；助手起始侧正文，不额外套装饰卡。长文本不截断，复制／失败／停止／重试操作可访问。
- 键盘、弹窗及离页时的请求行为见[聊天返回规则](chat.md#离页与返回)。
