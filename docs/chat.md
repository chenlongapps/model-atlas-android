# AI 助手：聊天与配置

从底栏的 `AI` 按钮进入独立全屏路由，右上角打开「会话配置」。填写完整 API 根路径、Bearer API Key 和服务实际接受的 Model ID，应用并保存成功后才能发送。保存不会发请求；地址格式见 [LLM 请求协议](llm-api.md#配置与调用)。

当前支持纯文本多行输入、Markdown 流式回复、复制、停止和显式重试。不接目录、实时价格、评测或工具，也不保存聊天历史。布局见[设计规范](Design.md#ai-助手)。

## 会话状态

- Activity 级 `ChatViewModel` 由助手页面与共享输入栏共用。`ChatScreen` 不包含编辑器；每轮回复独立收集增量，不为每个增量复制历史列表。
- 仅发送或显式重试创建请求，同一时间只生成一条回复。流正常结束才算完成；失败或停止保留部分文本。下一次请求只带已完成的用户／助手消息对，不带失败或停止轮次，不自动裁剪上下文。
- 无对话时，从题库随机展示三个不同的示例；每次打开助手重新抽取，普通重组不换题。配置就绪后点击直接发送，不修改手写草稿；保存配置不会补发。
- 仅末轮失败或停止可重试。复用原用户消息、替换旧回复，不自动续写；重试可能再次计费。
- 发送或读到末尾时跟随回复；向上阅读时保留锚点，回到末尾恢复跟随。
- 对话、输入和配置草稿只在 ViewModel 内存中，配置重建和离页重入可保留，进程结束丢失。SavedState 只存路由和页面阅读等 UI 状态。

### 助手回复排版

- `AssistantMarkdown` 使用 multiplatform-markdown-renderer 的 Material 3 组件。用户消息仍为纯文本；回复可选择，全文复制使用原始 Markdown，代码复制保留正文缩进但不含围栏。
- 普通和流式回复共用 GFM 强调兼容规则。代码、链接等先按 GFM 解析；配对粗体和斜体前，仅对相邻的 CJK 文字和标点放宽边界，且保留 GFM 已识别的样式。不改原字符或 AST 偏移，不插入空格。
- 每条可见回复独立维护增量解析状态。流中合并短时间内的累计文本快照，在后台只向库追加后缀；稳定块复用排版。完成、停止或失败时以最终原文完整解析一次，修正未闭合语法和后置引用；解析异常回退纯文本。跟随以消息区实际排版高度为准，不拉回向上阅读的用户。
- 仅显式点击可打开合法、无用户信息的 HTTP(S) 链接。图片只显示替代文字，不发请求；HTML 和数学公式显示原文，不执行或排版。代码在流中使用等宽文本，结束后为支持的语言后台高亮。

## 离页与返回

弹窗优先消费返回；否则先收键盘，再返回来源页。预测性返回取消不停止生成；确认退出或主动停止会同步取消请求，不等待动画。配置重建不取消或重发，ViewModel 销毁才随作用域取消。

退出首帧停用旧输入、配置、跟随和交互，清焦点但不清草稿；重入不自动弹键盘。导航结构见[架构](architecture.md#顶层分页与子页面)。

## 配置存储

`ai/config/` 的 `LlmConfigRepository` 只保存一套已提交配置。其 DataStore 独立于外观偏好，读写、保存与清除在 IO 上串行处理；请求客户端不访问存储。

| 项目 | 存储约定 |
| --- | --- |
| 文件 | `files/datastore/llm_config.preferences_pb`；`version = 1` |
| 非密钥字段 | `base_url`、`model_id` |
| API Key | `api_key_iv`（随机 12 字节）和 `api_key_ciphertext`（含 128 位认证标签），均为 Base64 |
| 加密密钥 | `KeystoreApiKeyCipher` 使用 AndroidKeyStore 中不可导出的 AES-256/GCM 密钥，别名 `modelatlas.ai.api-key.v1`；格式版本、带长度前缀的 URL 和模型 ID 作为 AAD |

先校验、加密，再一次原子写入；没有明文回退。运行配置及编辑草稿仍可在进程内持有 API Key；磁盘加密不保护已受控的应用进程，也不保证 StrongBox。旧式备份、云备份和设备迁移均排除此文件；换机需重新填写，Debug／Release 不共用凭据。

| 状态 | 行为 |
| --- | --- |
| 首次恢复 | 异步读一次，完成前禁止配置、发送和重试；不联网 |
| 应用配置 | 保存期间禁止重复提交、编辑、关闭和发送；成功才切换运行配置，内容变化才清空对话 |
| 保存失败 | 保留原配置、对话和未提交草稿；可重试或取消 |
| 读取失败 | 禁止覆盖和请求；可重试读取，或在面板中选择「重新配置」并明确确认删除旧配置。正常配置不显示清除入口。不自动修复损坏文件，不为旧密文生成替代密钥 |
| 确认重新配置 | 先清 DataStore 再删 Keystore 别名；仅此操作可替换损坏文件，已开始的文件清除不因取消中断。成功清空配置、输入和对话，并打开空白表单；部分失败也禁用旧凭据、清内存配置和对话。不撤销服务商 API Key |

不在日志、SavedState、备份或运行时 `local.properties` 中读写凭据。敏感类型脱敏，配置面板和清除确认启用 secure flag；密钥默认掩码，显式显示仅在当前面板内有效。显式复制消息时标记剪贴板内容敏感。UI 只接收安全错误类型，不展示原始错误。

选测见[分级测试](testing.md#ai)；文件重开测试不等于真实进程恢复或设备迁移验收。
