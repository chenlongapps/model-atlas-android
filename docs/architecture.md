# 架构说明

单模块 `:app`，入口为 `MainActivity` → `ModelAtlasTheme` → `ModelAtlasApp`。以下包均相对于 [`app/src/main/java/io/github/chenlongapps/modelatlas/`](../app/src/main/java/io/github/chenlongapps/modelatlas/)。

| 包 | 职责 |
| --- | --- |
| `data/remote/`、`data/mapper/` | 拉取 Atlas 和 Models.dev，用独立 DTO 映射到本地类型，再将本地投影映射到应用模型 |
| `data/local/`、`data/repository/` | Room3、查询与事务；仓库协调同步和业务投影 |
| `ui/` | Route 获取 ViewModel 并感知生命周期收集；`Screen(uiState, callbacks)` 不依赖注入 |
| `ui/navigation/`、`ui/transition/` | 主路由与助手、共享底栏、模型／榜单共享转场 |
| `ui/components/glass/` | Liquid Glass 表面、样式与背景采样 |
| `ai/`、`ui/chat/` | [LLM 请求](llm-api.md)与[聊天和配置](chat.md)，不参与目录同步 |

DTO、本地 Entity／JSON 和应用模型独立。Repository 不触发导航；UI 保存展开、阅读和弹层，ViewModel 保存查询与业务选择，整份目录不写入 SavedState。字段见[页面字段](page-information.md)，布局与交互见[页面设计约束](page-design.md)。

## 数据与状态流转

首次无目录且无发布标记时导入随包 Atlas（无报价）。启动先读本地，再后台同步；已有空发布也视为已初始化。确无本地数据时等待首次联网读取完成，避免加载中闪现空态。

`DefaultModelRepository.refresh()` 并行读取 [Atlas 整包](atlas-data.md#发布校验及同步)和 [Models.dev](data-source.md#请求与解析)。任一来源失败或取消都不写半份。同一轮启动／主动刷新／Debug 调用共享在途请求，等待者取消不取消这一轮，发起者取消则通知等待者。不同快照才[事务提交](local-data.md#快照事务与查询)，不轮询或安排退出后的同步。

### 缓存与列表展示快照

- 模型列表只在启动、主动刷新成功或 Debug 显式变更后重读快照，不持续订阅目录。后台写库不会改变当前列表；切页、详情返回和配置重建也不重新发布。新 ViewModel 读取最新缓存。
- 下拉刷新在联网和重读都成功后才替换展示快照，保留查询、展开与阅读位置。数据库或展示快照任一变化报「已更新」，均不变才报「已是最新」。刷新失败不替换快照；[反馈与重试](page-design.md#刷新反馈)见页面约束。
- 目录和报价是独立投影，仓库组合后去重、收录和选价。`ModelListQuery` 本地匹配：搜索各词都须命中名称／ID／LAB 之一；不同筛选字段取交集，LAB 多选取并集，每个方向满足全部选中模态。候选来自完整快照与已选项，不随匹配结果收窄；[筛选提交](page-design.md#模型列表)见页面约束。恢复旧查询时忽略已移除的上下文／最大输出门槛和报价筛选。
- 设置的「展示说明」目录总数复用同一 `ModelListViewModel` 已发布的未筛选快照，不另读缓存或联网；首次加载或目录读取失败时不显示总数。

## 顶层分页与子页面

`AssistantNavigation` 用 Navigation 3 管 Main 与独立的助手路由。Main Pager 管[顶层分页](page-design.md#悬浮底部导航)；详情、全榜、外观、来源许可和 Debug 数据库仍是 Main 子页。局部改动不附带迁移路由。

共享底栏在 `NavDisplay` 外，助手使用同一容器作输入栏。主路由自动隐藏只观察当前停稳页消耗的纵向用户滚动，不消费位移，不响应惯性、程序滚动或弹层。显隐效果见[悬浮底部导航](page-design.md#悬浮底部导航)，默认值与保存见[底栏偏好](appearance-settings.md#底栏偏好)。

### 玻璃表面与采样

- `Modifier.glassSurface` 与 `GlassSurface` 使用同一绘制逻辑。`Standard` 用于共享底栏；`Subtle` 用较实的着色维持聊天顶部按钮对比度；`Indicator` 用较弱折射和独立色相叠加。调用方按主题和交互状态传入着色与降级色。
- 每个采样区域用 `rememberGlassBackdrop` 创建一个源，并用 `captureGlassBackdrop` 标记背景层。底栏共用 `NavDisplay` 源（含圆形揭示）；聊天顶部按钮只采样消息与两端渐隐，不采样自身。换主题只更新背景色；底栏由导航变为输入栏时，着色更新不重建采样源或光学效果。
- Preview、未提供采样源、缺少 RenderEffect 或软件渲染宿主使用不透明主题底色，不采集背景。没有运行时着色器或形状不支持折射时保留模糊与着色；折射只用于圆角矩形类形状。

### 路由与返回

Main 和助手共享稳定的 Navigation 3 Scene。助手入栈后立即停用 Main 交互与读屏；Main 保留布局，助手全屏时跳过 Main 绘制。预测性返回只改变圆形裁剪，确认时先停用助手交互，收缩完成才弹栈；取消不会改变路由。配置重建按已保存的路由和退出意图恢复，不重放入场或手势。返回恢复来源页的阅读、展开和指示器，不触发目录刷新。

子页打开时 Main Pager 不放置，转场期间可保留两端布局；隐藏或退场的页面不可触摸、聚焦或读屏。弹层优先返回；[助手返回](chat.md#离页与返回)另处理键盘和请求。

## 收藏的数据与状态

用户增删实时生效，但目录中的收藏身份与可用性绑定当前展示快照，不随后台更新跳卡。匹配后稳定前置收藏；不可用项只留历史身份且不计目录总数。写入按数据库结果更新；取消收藏成功才返回，失败留在详情。详情退出后再释放来源位置、重排或淡出。持久化见[本地收藏](local-data.md#本地收藏)。

## 评测总览与完整榜单

`RoomBenchmarkRepository` 同事务读定义、成绩与模型身份。总览只在停稳且生命周期可见时观察，打开全榜保留订阅；恢复或本地重试不联网。主动刷新复用目录请求，提交后重读榜单，不替模型页发布快照；[刷新反馈](page-design.md#刷新反馈)由模型与评测共用。持续观察失败清旧成绩。全榜只保存榜单 ID 与阅读状态，确认退出交接后清理阅读位置。

### 排名、分榜与坐标

- 总览按 `popularity` 降序，缺失最后；同值按名称（忽略大小写）、榜单版本、榜单 ID 排序。榜单继承定义热度。
- 只有精确关联定义的当前 LLM 可参榜，按定义版本、指标与单位分榜；定义声明的兼容版本并入 `definition.version` 同一榜单，`unspecified` 定义下的成绩同样归一个版本。成绩原始版本不改写。匹配规则见 [Atlas 契约](atlas-data.md#成绩及本地化)，旧缓存关联可[离线修复](local-data.md#独立评测成绩)。
- 只排名有限数值且高分更优的成绩。每模型取未舍入最高分，同模型同分按成绩 ID 选；模型同分并列后跳号，同分组按名称／模型 ID 稳定排序。不丢弃详情的其他配置。
- `BenchmarkChart.kt` 按数据范围和有效定义边界取局部坐标。总览用 Top 3，全榜用全部排名；坐标不随滚动变化，单值也保留非零区间。

## 双模型对比的数据与状态

`ModelCompareViewModel` 只保存两个不同的规范 ID，保留槽位顺序。已有 `SavedStateHandle` 优先（含明确清空的槽位），否则首次可见时从 [DataStore](appearance-settings.md#存储和备份边界) 读取；等待期间不展示空槽位或接受编辑。选择、替换和移除立即更新界面和 SavedState，按操作顺序原子写入两个 ID；新页面读取前等待先前已入队的写入，初始化不回写。读失败保留存储原值并可重试，写失败保留当前选择并可重试。

停稳且可见才观察目录和模型详情，重试不联网。默认价取目录投影，参数和能力取各自详情。模型找不到或读取失败时不保留失效数据，也不删除 ID；替换时取消旧订阅。UI 保存「仅看差异」与正文滚动；等待详情或默认报价时使用独立列表状态。主动补选空槽凑齐两侧时，从当前选模位置展开新正文，不回到上一组的正文位置。规格先以精确数值、布尔值及归一的无序模态集合比较，再格式化；切换筛选不重建列表或主动滚动。

评测使用两侧详情中有有效分数的记录（有限数值或非空原文），不读榜单的最高分投影。按匹配的定义 ID、明确的实际版本／指标／单位分组，合成测试与真实数据分开。每侧独立选最高已知思考档位（关闭、极低、低、中、高、超高、最高；忽略大小写并支持常见别名），未知档位不参与排序；只有整侧均未报告档位时才使用未报告记录。

- 优先展示严格配对：两侧最高档记录须有唯一一对运行条件匹配。数据集与 Harness 必须明确，工具、变体、来源、来源类型、日期及分数方向须一致；仅有同一明确出处时才允许缺报工具、变体或思考档位。
- 未严格配对的评测可作为参考：允许同一定义显式声明的兼容版本合并候选（详情投影定义版本但保留成绩原始版本）；同样只看各侧最高档，不混配已报告与未报告档位。要求两侧有唯一共同成绩来源：优先精确的 HTTP(S) 来源链接，无共同链接时才按相同主机名尝试；匹配来源内每侧必须恰好一条。主机名一致只用于选参考记录，不证明运行条件一致。有歧义时不任选、不降档，所有成绩均不计算差值。

## 模型详情的数据与导航

`ModelDetailViewModel` 按规范 ID 读取[本地事务详情](local-data.md#快照事务与查询)，不联网重试。打开时用临时身份快照展示头部，真实结果原位接管，失败或移除时清除；恢复只依赖 ID。概览、价格和评测共用外层标题与标签位置，各正文独立保存滚动。外链经 `DetailLink.kt` 校验，只允许合法、无用户信息的 HTTP(S) 链接。

### 共享转场与预测性返回

- 模型与榜单各用独立 key：模型用规范 ID，榜单用完整榜单 ID。榜单前三名动画再按模型 ID 和元素角色匹配，不按名次或名称匹配。滚动后停止身份匹配，容器仍可返回来源；找不到来源则淡出，不强制回顶或保留过期成绩。
- `ModelSharedTransition.kt` 和 `BenchmarkSharedTransition.kt` 在同一条 450ms 时间轴上保留两端布局。`RetainedPageTransitionController` 按系统动画倍率驱动；取消恢复稳定页面与阅读，确认只走完剩余转场，再清选中 ID，交接完成后释放保留页和订阅。
- 不用固定延时或 `isRunning` 判断交接。控制器在端点用 `snapTo()` 避免旧 segment 被重放；倒放先确认两端目标已组合、经过下一帧才归整，避免 Logo 在交接时短暂消失。
- 配置恢复不保存进行中的手势。改公共控制器同时回归两条链路，覆盖入场中返回、暂停、取消、确认、来源移除与零动画。dispatcher 和像素测试不能替代真实系统边缘手势。
