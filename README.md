# ModelAtlas Android

基于 Kotlin 和 Jetpack Compose 的 Android 应用，用于发现、了解和对比 AI 模型。

> 🚧 项目处于早期开发阶段，已接入 Models.dev 真实目录，支持本地优先浏览 LLM、搜索与组合筛选，以及模型详情和全部显式关联的服务商报价。双模型对比尚未实现。

## 已实现

- `MainActivity` 启动入口与 Hilt 依赖注入
- 悬浮玻璃底部导航：Release 为“模型｜设置”，Debug 追加同级“调试”标签，支持点击／滑动切换，保留各页状态；设置页提供“数据来源与许可”独立页面入口，Android 10/11 导航使用实色胶囊兜底
- 紧凑圆角模型卡片：彩色 logo、LAB 与权重许可标签、图标参数行和方向模态标签；浅色／深色随系统切换，Android 12 及以上跟随壁纸动态取色，低版本使用固定备用配色
- 真实数据链路：Retrofit / OkHttp → 独立 DTO 映射 → Room3 事务写入 → Flow → ViewModel → Compose 列表
- 每个规范模型一行，展示名称、LAB（模型 ID 第一个 `/` 前的部分）及其彩色 logo、发布时间、token 限制（列表用 `1M`、`384K` 等十进制缩写，读屏保留精确值）、输入／输出模态与开放权重（`open_weights` 三态，短许可显示为“开放权重 · MIT”，长名称保留在数据中、不在列表展开；“开放权重”不等于开源或允许商用）；缺失信息显示“暂无数据”。LAB logo 为随包的 Models.dev 品牌素材，只覆盖 23 个实验室，没有素材时显示兜底图，不借用其他实验室的 logo
- 每个模型展示一条报价：能力与价格仅用细分隔线分区，不嵌套内层价格卡片；价格区跟随系统动态配色，注明「API 价格 · 美元 / 1M tokens」，输入／输出与存在时的缓存命中输入使用分列单价，窄屏或大字体自动换行，其他单价逐行展示；有上下文档位时点击标题展开，档位门槛仍显示完整精确数值。不显示服务商；官方报价优先，否则按内置第三方优先级选一家。没有可用报价显示「价格：暂无数据」，明确的零价显示 `$0.00`
- LLM 收录规则、多模态文本模型支持，以及首次加载骨架扫光（Skeleton + Shimmer）、空数据、失败重试状态；已有目录刷新时保留真实列表
- 本地目录优先浏览，仅模型增删提示确认，内容变化静默同步；支持下拉主动刷新，网络失败保留本地列表
- 胶囊搜索框按名称、稳定 ID 或 LAB 实时搜索；按 LAB、权重公开三态、输入／输出模态、最低上下文／最大输出 tokens 及有无列表报价组合筛选，底部面板预览结果、确认应用，关闭放弃草稿；支持可移除条件标签、清空搜索、重置筛选和无结果时清除全部条件，切页、刷新及状态恢复保留已应用条件
- 三张 Room3 目录表及独立 JSON 值对象，保留模型与服务、报价、稳定标识和获取时间（见[本地目录数据](docs/local-data.md)）
- 设置中的独立说明页集中展示数据来源、独立第三方身份、价格适用条件与 Models.dev MIT 许可全文
- Debug 底栏“调试”页提供应用／设备信息查看与复制、本地目录三表数量、手动刷新目录；切页保留滚动，不再放在设置中，Release 使用空实现，不包含调试标签、真实页面或专用资源
- 点击卡片打开独立模型详情：完整 ID、描述、系列、精确 token 限制、知识截止时间、能力三态、完整许可及权重／资料外链；按服务商展示所有显式关联的模型服务（含无报价服务）、基础与独立模式报价和精确档位，服务参数与规范模型分开。详情读取本地目录，不重复联网；支持加载、读取失败重试、模型移除状态及按钮／系统返回，保留列表阅读状态
- 点击模型卡片以约 450ms 的整卡放大动画展开为全屏详情，圆角与底色连续过渡，同时保留 Logo、模型名称、研发机构与权重标签的双向共享元素动画；背景列表不整页淡出，详情滚动后仍能收回整卡，缺少容器匹配时才淡出兜底。异步加载使用临时身份快照，保留列表状态并遵循系统动画设置；尚未接入预测性返回进度联动
- 详情展示各记录的上游更新时间和本地获取时间，两者不代表价格生效时间；相同内容不重复写库时保留原获取时间
- 详情采用居中放大的 Logo／模型名及独立参数卡，页头与正文使用一致背景，不绘制彩色渐变，复用列表品牌素材、标签和数值缩写；技术参数与读屏保留精确值。通过“概览／价格／评测”三个标签切换，概览依次包含能力、技术参数、权重许可、相关资料与来源时效；身份区与标签栏随正文滚动，固定返回栏在上滑时由品牌名自然过渡为模型名称，各标签独立保存滚动与展开状态；窄屏大字号支持横向滚动标签。评测展示 Models.dev 已有的原始分数、口径与出处，不生成排名或推断不同配置可比性，无数据时显示空态

## 功能规划

- 对比多个模型的参数与价格
- 收藏模型，在目录页展示更新时间
- 后续扩展：价格追踪、新模型提醒、模型更新历史

## 技术栈

Kotlin · Jetpack Compose · Material 3 · MVVM · Hilt · Retrofit / OkHttp · Kotlinx Serialization · Room · Coroutines / Flow

## 数据来源

通过 [Models.dev](https://models.dev/) 的公开 API 获取数据：[models.json?type=all](https://models.dev/models.json?type=all) 提供规范模型，[api.json?type=all](https://models.dev/api.json?type=all) 提供服务商与模型服务。两个响应均成功后原子更新本地目录，列表只收录符合规则的 LLM；未显式关联的服务不猜测匹配。上游定价统一为 USD / 百万 tokens，报价已存储并在列表展示，选取规则与计价语义见[数据源说明](docs/data-source.md)。

进入列表时优先读取本地目录，并在后台检查最新目录；仅规范模型 ID 集合发生增删时提示“立即更新”，用户确认后应用完整快照。ID 集合不变时，参数、价格及服务商等内容变化静默同步，不显示更新提醒；内容一致不重复写库。下拉刷新会主动获取并应用最新目录；后台检查中下拉则复用该请求。网络失败仍可浏览已有本地列表与详情，首次无数据时提供加载与失败重试，不使用示例数据。不轮询，也不在退出应用后定时检查；目录页的统一更新时间尚未实现。Models.dev 上游 MIT 许可全文随应用打包，可通过设置 →“数据来源与许可”查看。

本项目为独立第三方应用，与 Models.dev 及各 AI 模型提供商无官方隶属关系。
